## Loading, empty, error, denied, and offline states

| State | Required behavior |
|---|---|
| loading | Скелетоны трёх карточек без ложного контента. |
| empty | Объяснение выбранного района, кнопки «Создать карточку» и «Изменить район». |
| error | Сохранённая лента остаётся видимой с сообщением и действием «Повторить». |
| denied | При отказе в геопозиции предлагается ручной выбор района; при отказе в фото карточку можно создать без изображения. |
| offline | Показывается локальный снимок; создание и отклик ставятся в очередь с явной отметкой. |
