# Core loop and critical flows

**Core loop:** open_relay — Человек видит текущий ход, условие и цепочку знакомых участников → accept_turn — Текущий ход закрепляется за участником и открывает создание продолжения → capture_chapter — Снятый результат становится новой видимой главой эстафеты → pass_turn — Следующий знакомый получает персональный ход с готовым продолжением

**Return reason:** Участник возвращается, чтобы увидеть ответ следующего знакомого и движение персонально переданной цепочки.

| Flow | Start | Actions | Outcome |
|---|---|---|---|
| Приёмочный сценарий 1 | relay_feed | open_relay → accept_turn → capture_chapter | Снятый результат становится новой видимой главой эстафеты |
| Приёмочный сценарий 2 | messages | pass_turn | Следующий знакомый получает персональный ход с готовым продолжением |
