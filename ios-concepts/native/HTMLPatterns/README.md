# HTML concept knowledge

This directory contains product and composition knowledge harvested from the
HTML concepts. It deliberately contains no HTML, CSS, DOM selectors or web
runtime.

Each pattern has a stable id, the native recipe families it can influence, an
implementation-independent rule and provenance from the source concept. The
catalog is an input to generation, not a screen template: the product world
model decides whether a pattern applies and the native reference profile decides
how it is rendered on iOS.

`screenshots/` contains a deliberately small visual calibration set. The catalog
links each image to a concrete observation, so an agent can inspect hierarchy,
density and content attachment without treating the pixels as a layout to copy.
