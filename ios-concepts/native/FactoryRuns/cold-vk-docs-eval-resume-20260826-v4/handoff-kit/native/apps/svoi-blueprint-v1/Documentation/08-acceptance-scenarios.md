# Сценарии приёмки

| Сценарий | Старт | Действия | Результат | Восстановление |
|---|---|---|---|---|
| Локальный вход открывает наполненную ленту | login | request_email_code → verify_email_code → open_feed | После ввода показанного локального кода активна session-alex, а лента содержит deed-bench, deed-garden и deed-library. | Неверный код не создаёт сессию; можно запросить новый детерминированный код. |
| Пользователь публикует конкретное дело | create | create_deed → edit_deed_text → choose_deed_photo → choose_deed_place → publish_deed | Новое active-дело появляется первым среди дел близкого круга с импортированным фото и местом. | При пустом результате черновик сохраняется и показывается «Опишите конкретный результат.» |
| Друг поддерживает дело, предлагает помощь и подписывается | feed | support_deed → offer_help → follow_result | У deed-bench увеличена поддержка, создан contribution kind=offer и user-marina записан в followers. | Повторная поддержка не дублируется; пустое предложение остаётся черновиком. |
| Комментарий открывается и создаётся отдельными действиями | feed | open_comments → respond_to_post | Открывается comments для deed-garden, а новый комментарий появляется в ветке и увеличивает commentCount. | Пустой текст не публикуется и экран комментариев остаётся открыт. |
| Дело проходит от обновления до доказанного завершения | post_detail | add_update → add_contribution → choose_deed_photo → complete_deed → thank_helpers → take_baton | Исходное дело становится completed с доказательством и благодарностями; создаётся связанный черновик с parentDeedId. | Без доказательства завершение не применяется, обновления и вклады сохраняются. |
| Голосовое обновление записывается, расшифровывается и играет в фоне | post_detail | record_voice_update → transcribe_voice_update → play_voice_update | Update содержит audioPath, transcript и активный Now Playing с правильным названием дела. | При отказе в микрофоне или speech доступны текстовое обновление и ручная подпись. |
| Участник подключается и подтверждает площадку | post_detail | join_deed_network → verify_site_network → add_contribution | Для deed-garden сохранены connected=true, verified=true и выполненный вклад участника. | При ошибке подключения показываются SSID и ручная инструкция; вклад можно подтвердить фото. |
| Диалог поддерживает сообщение и локальный системный звонок | messages | open_conversation → send_message → start_helper_call | Сообщение delivered и завершённая запись CallKit-звонка появляются в conversation-marina. | Если звонок недоступен, диалог остаётся открыт и предлагает отправить сообщение. |
| Подписка даёт наблюдаемое фоновое обновление | notifications | enable_result_alerts → apply_silent_snapshot → refresh_feed_on_fetch → schedule_digest_task | Версия snapshot повышена, fixture-обновление видно в ленте, а digest сообщает два изменения. | При запрете уведомлений данные обновляются при открытии и остаются в центре приложения. |
| Виджет публикует обновление от вошедшего пользователя | settings | share_session_with_widget → publish_quick_update_widget | update-widget-1 появляется в App Group, виджете и истории deed-bench от user-alex. | Без общей сессии виджет не показывает данные и открывает приложение для входа. |
| Приватное дело защищено биометрией | private_deeds | unlock_private_deeds → open_deed | После успешной проверки видно deed-private; после ухода в фон список снова закрыт. | После отказа содержимое и заголовки приватных дел не раскрываются. |
| Календарное событие возвращает в конкретное дело | post_detail | add_deadline_to_calendar → open_deed_link | Событие хранит Universal Link, который открывает deed-bench внутри приложения. | При запрете календаря срок остаётся в деле; неизвестный link показывает состояние отсутствующей записи. |
| Круг помощников пополняется без обязательного доступа к контактам | settings | import_helpers → search_world → open_search_result | При разрешении выбранный контакт добавлен в circle; при отказе тот же пользователь находится ручным поиском. | Отказ не блокирует создание дел, помощь и сообщения. |
| Отказ в tracking не влияет на основной цикл | settings | enable_promotion_measurement → open_feed → support_deed | Сохраняется contextualOnly, лента не меняет порядок, поддержка дела работает. | Настройку можно выключить; локальные продуктовые события продолжают собираться без межприложного идентификатора. |
| Credential Provider хранит идентификатор, но не обходит код | settings | manage_demo_credential → request_email_code → verify_email_code | Почта подставлена из provider record, новый локальный код проверен, новая сессия активна. | После удаления записи вход остаётся доступен ручным вводом почты. |

## Доступы

- **camera**: Открыть новое дело, нажать «Снять фото», разрешить доступ, сделать снимок и убедиться, что он прикреплён.; при отказе: Остаются выбор из медиатеки и текстовое доказательство.
- **photos**: Выбрать fixture-изображение в PHPicker и проверить его в черновике после повторного открытия.; при отказе: Можно снять фото или продолжить без изображения.
- **mic**: Разрешить микрофон, записать три секунды, остановить и воспроизвести файл из обновления.; при отказе: Пользователь вводит обновление текстом.
- **location**: Запретить доступ, ввести «Двор на Абая» вручную и опубликовать дело с этим местом.; при отказе: Доступен ручной ввод названия без координат.
- **push**: Подписаться на дело, разрешить уведомления, применить fixture-обновление и открыть уведомление в нужное дело.; при отказе: Изменения остаются в разделе «Уведомления» внутри приложения.
- **commnotif**: Включить настройку, запустить fixture-сообщение от Марины и открыть conversation-marina из уведомления.; при отказе: Непрочитанное сообщение показывается значком внутри вкладки.
- **remotenotif**: Передать тестовый silent payload snapshotVersion=4 и проверить версию и обновление deed-garden.; при отказе: Снимок обновляется при ручном открытии ленты.
- **fetch**: Положить update-fetch-1 в локальную очередь, симулировать fetch и проверить его в deed-bench.; при отказе: Очередь применяется при foreground-запуске.
- **bgtask**: Включить дайджест, симулировать запуск зарегистрированной задачи и проверить changedCount=2.; при отказе: Дайджест рассчитывается при открытии профиля.
- **appgroups**: Ввести «Краска куплена» в виджете, открыть приложение и проверить update-widget-1.; при отказе: То же обновление добавляется из экрана дела.
- **keychain**: Войти, перезапустить устройство в тесте и проверить, что виджет видит user-alex, но не хранит email-код.; при отказе: Виджет предлагает открыть приложение без показа приватных данных.
- **autofill**: Сохранить alex@example.test, выйти, выбрать запись провайдера и запросить новый локальный код.; при отказе: Почта и код вводятся вручную.
- **wifiinfo**: Для deed-garden вернуть тестовый SSID Svoi-Yard и проверить verified=true.; при отказе: Помощник подтверждает площадку фото или ручной отметкой.
- **contacts**: Разрешить fixture-контакты, выбрать Марину и проверить user-marina в circle-alex.; при отказе: Доступен ручной поиск по имени или почте.
- **tracking**: Отказать в ATT, открыть promoted fixture и проверить contextualOnly без изменения ранжирования.; при отказе: Используются только агрегированные локальные показы без межприложного идентификатора.
- **faceid**: Открыть раздел, успешно пройти Face ID, увидеть deed-private; отправить приложение в фон и проверить повторную блокировку.; при отказе: Доступен код устройства; при неуспехе содержимое остаётся скрытым.
- **speech**: Разрешить распознавание, обработать fixture audio-update-1 и проверить заданный transcript.; при отказе: Автор вводит подпись вручную; аудио остаётся доступным.
- **audio**: Запустить audio-update-1, заблокировать экран, проверить название дела и паузу в Now Playing.; при отказе: При невозможности фонового режима запись играет только внутри приложения.
- **voip**: Позвонить Марине, дождаться локального соединения, завершить и проверить call-marina-1 в диалоге.; при отказе: Координация продолжается текстовыми и голосовыми сообщениями.
- **calendar**: Добавить срок deed-bench в тестовый календарь и проверить eventIdentifier и ссылку.; при отказе: Срок остаётся видимым в деле и локальном дайджесте.
- **associateddomains**: Открыть https://svoi.example/deeds/deed-garden и проверить экран deed_detail с правильным id.; при отказе: В браузере показывается статическая страница с предложением открыть приложение.
- **hotspot**: Применить тестовую конфигурацию Svoi-Yard, симулировать успех и проверить siteConnection у deed-garden.; при отказе: Показываются имя сети и инструкция для ручного подключения в настройках iOS.

## Обязательные проверки

- Вход принимает любой полный четырёхзначный локальный код.
- Каждая кнопка имеет один предсказуемый outcome.
- Комментарий открывает тред, ответ изменяет исходный пост.
- Все root и pushed экраны достижимы и возвращаются предсказуемо.
