## Setup, build, and run

**Prerequisites**

- iOS 17+ simulator or device
- Настроенный App Group identifier
- Зарегистрированные extension targets

**Build**

- `Выбрать схему приложения с Share и Notification Service extensions`
- `Собрать Debug с локальными demo adapters`

**Run and verify**

- `Войти кодом 246810 для демонстрационной почты`
- `Проверить populated и переключаемые состояния адаптера`
- `Перезапустить приложение и проверить сессию`
