# Чего не хватает для сильного переноса всех HTML-концептов

1. Полные скриншотные наборы VK Музыки, VK Видео и Одноклассников по спискам в `REFERENCE-PROFILES.md`.
2. Карта главного flow каждого продукта: старт, happy path, возврат, пусто, ошибка, offline.
3. Таблица ожидаемого результата каждой кнопки и место хранения результата.
4. Реальные примеры контента, включая длинные имена, тексты, пустые списки и ошибки.
5. Оригинальные фото/видео/обложки и правила лицензирования; цветные иконки-плейсхолдеры не принимаются.
6. Контракты backend/API для функций, которые нельзя честно реализовать локально.
7. Приоритеты концептов и одно главное пользовательское обещание для каждого.
8. Целевые устройства, минимальная iOS, Dynamic Type, локализации, light/dark и требования доступности.
9. Для нового VK-mimicry профиля — подтверждение product-chrome icon map. В нативном SwiftUI Looks и Dvor уже используют проверенный локальный Lucide 0.525.0 asset set только в системном `TabView`; permission/platform actions остаются SF Symbols. Случайные SVG и runtime-загрузка запрещены.

Без этих входов можно построить качественный нативный каркас, но нельзя честно обещать точную мимикрию, реальную серверную логику и 10/10 для каждого состояния.
