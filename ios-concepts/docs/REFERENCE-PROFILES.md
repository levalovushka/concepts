# Профили мимикрии

## ВКонтакте

Профиль подключён для «Образов» и «Двора»: оба концепта намеренно являются
VK-mimicry. Он задаёт социальную плотность, ленту, root header, списки, чат,
сервисы, цвета, типографику и audited Lucide product-chrome roles для root tabs.
Liquid Glass и сам `TabView` остаются системным chrome iOS; permission/platform
actions используют SF Symbols.

## VK Музыка — ждёт evidence

Нужны актуальные iPhone-скриншоты: запуск, главная, поиск, медиатека, альбом, артист, плеер, очередь, скачанное, пустое состояние и offline.

## VK Видео — ждёт evidence

Нужны: запуск, главная, поиск, подписки, карточка видео, плеер, комментарии, короткое видео, пустое состояние и offline.

## Одноклассники — ждёт evidence

Нужны: лента, рекомендации, сообщения, видео, меню, профиль, пост, группа, настройки, пустое состояние и offline.

Для каждого кадра нужны модель iPhone, версия iOS, версия приложения, дата, светлая/тёмная тема и размер текста. По одному красивому скриншоту профиль не строится: нужны состояния, переходы и повторяющиеся правила.

`npm run profiles` печатает точные блокеры. Пока evidence нет, компилятор не разрешит концепту заявить мимикрию соответствующего продукта.
