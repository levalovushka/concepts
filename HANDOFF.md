# Передача: где мы находимся и что делать дальше

Документ для продолжения в новой сессии. Ветка `feature/pipeline-native-swiftui`.

---

## Что это за работа

Пайплайн v5: из `concept.json` собирается нативное iOS-приложение на SwiftUI.
Первый концепт — **«Образы»** (`looks`), мимикрия под ВКонтакте, набор `vkontakte`,
21 доступ. Спека — [PIPELINE-V5.md](PIPELINE-V5.md), предыстория провалов —
[WHY-REWORK.md](WHY-REWORK.md).

## Состояние

```
platform/native/
  vk-visual-profile.md      источник правды по мимикрии (переписан по iOS-скринам ВК)
  DesignSystem/             токены + VK-компоненты (слой совместимости снят)
  Runtime/                  доступы на реальных iOS API, навигация, снекбар
  apps/looks/               экраны «Образов» — пишутся руками, ~3000 строк
  gen/gen-project.mjs       Info.plist из спеки + Xcode-проект
  gen/shots.mjs             съёмка всех экранов (пересобирает сама, есть ворота свежести)
  gen/audit-permissions.mjs ворота: каждый ключ имеет фичу и ровно одну точку запроса
  gen/audit-nav.mjs         ворота: маршрут достижим, вкладки не прыгают, аватар на месте
  gen/audit-ui.mjs          ворота: подпись у кнопки-иконки, кегль не мельче 11 pt
  gen/critic.md             правила агента-критика
platform/launcher/          Mac-приложение: библиотека концептов, запуск в симуляторе, доки
```

Команды из `platform/`:

```bash
node native/gen/gen-project.mjs looks
cd native/build/looks && xcodebuild -project Looks.xcodeproj -target Looks -sdk iphonesimulator -configuration Debug build
node native/gen/shots.mjs looks           # без списка — снимает все 22 экрана
node native/gen/audit-permissions.mjs looks
node native/gen/audit-nav.mjs looks
node native/gen/audit-ui.mjs looks
```

`shots.mjs` без списка экранов снимает **все**: список выводится из режима
съёмки в `App.swift`, руками его больше не держим.

## Что уже сделано

- **Доступы: 21 из 21 отработаны**, аудит зелёный. Доступы вплетены в продуктовые
  места, а не вынесены отдельными экранами-заглушками.
- **Мимикрия переписана по iOS-скринам ВК**: белый фон (не серый), действия поста
  голыми иконками, профиль на сером с белыми карточками. Лента, профиль и настройки
  приведены к ВК.
- **Агент-критик работает** и ловит то, что автор пропускает.
- **Навигация разобрана против ВК** (замечание заказчика закрыто):
  профиль — не вкладка, вход в него только мини-аватаром слева сверху на каждой
  корневой вкладке; «‹» в шапке профиля работает, прыжков в чужую вкладку нет,
  «Отметка на свопе» перестала быть недостижимой. Настройки — одна дверь:
  плитка в «Меню», как у ВК. Держит это `gen/audit-nav.mjs`.
- **`shots.mjs` действительно снимает сегодняшний интерфейс**: он пересобирал
  проект, но не перекладывал исходники из `apps/<slug>` — ворота свежести
  не срабатывали, и кадр приходил вчерашний. Теперь перед сборкой идёт
  `gen-project.mjs`.
- **Все экраны сверены с iOS-скринами ВК.** Таб-бар стал пятииконочным по форме
  ВК (дом · поиск · сообщения · клипы · меню), появился «Поиск» с мозаикой в три
  колонки, «Меню» с плитками 64/18 и «Настройками» плиткой внутри сетки, клипы
  получили верхние табы, дизлайк, «···» и «Оригинальный звук», чат — серые
  входящие с аватаром у первого в группе, разделители дат и общий градиент
  исходящих через весь тред, «Знакомые» переписаны по экрану «Друзья».
- **Слой совместимости `Legacy.swift` снят.** Его компоненты либо переехали в
  `DesignSystem/Components.swift` под именами ВК (`VKCard`, `VKFilterPills`,
  `VKGridCell`), либо заменены на существующие. Новое в ДС: `VKGroup` (белый
  блок с серой полосой — из-за его отсутствия белые карточки на белом фоне
  не читались вовсе), `VKPersonRow`, `VKPostActions`, `VKMosaic`, `VKDarkTabs`,
  `VKClipAction`, `VKSoundCapsule`, `VKOutlineCapsule`.
- **Mac-лаунчер** собирается и запускает концепты; не может жить в Mac App Store
  (песочница запрещает `simctl`) — путь Developer ID + нотаризация + Sparkle.

## Что делать дальше — по приоритету

### 1. Спека разъехалась с приложением

`gen/audit-nav.mjs` это печатает и не блокирует — решение за заказчиком:

```
! вкладки: спека [home · nearby · chats · profile] — приложение [home · search · chats · clip · menu]
! экраны есть в приложении, но не в спеке: search, services, wardrobe, event
```

`concept.json` описывает **веб-прототип** (`concepts/looks/screens/*.html`),
а нативное приложение ушло вперёд. Либо спека и веб-сборка догоняют навигацию,
либо нативная сборка объявляется главной и спека перерезается под неё. Пока
этого не решено, `tabs` в спеке врут.

### 2. Только потом — вынос скелета в дизайн-систему

Замерено: из ~3000 строк экранов около половины — это скелет ВК (лента, чаты, чат,
профиль, сервисы, клипы), написанный внутри `apps/looks/` и привязанный к
`LooksStore`. В наборе `vkontakte` ждут ещё **6 концептов** — по текущей
архитектуре каждый потребует переписать этот скелет заново. Часть работы уже
сделана снятием `Legacy.swift`: общие куски переехали в `DesignSystem/`.

Заказчик решил: **сначала довести качество UI, потом выносить** — иначе плохой
скелет размножится на все концепты.

## Решения заказчика, которые нельзя пересматривать

- **Таб-бар — нативный Liquid Glass** iOS 26, копировать плоский бар ВК не нужно.
- **Изображений нет, только SF Symbols.**
- **Эталон качества** — топовые продуктовые приложения уровня Revolut/Wise.
- **Визуальное качество важнее достоверности доступов** (доступы — второй приоритет).
- **Ничего лишнего**: фича, которая не отрабатывает доступ и не нужна структурно
  для мимикрии, в концепте не нужна.
- **Отличия продукта живут в модели контента**, а не интерфейсными виджетами
  поверх знакомых паттернов ВК.

## Открытый вопрос к заказчику

`concept.json` «Образов» заявляет три отличия: «отметки вещей на фото»,
«профиль как живой гардероб», «ремикс образа своими вещами». Заказчик забраковал
два из трёх (отметки на постах — «не мимикрия ВК», ремикс — «непонятно что за
функционал»). Из ленты они убраны, но **остались на экране образа и в создании** («Отметить
вещи») и в спеке. Нужно решение:
переписать `distinctions`, признать отметки VK-native паттерном (отметки на фото)
или переводить концепт в отстройку.
