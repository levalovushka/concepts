# Дизайн-система

Тёмная грамматика VK Музыки: фон `#19191B`, поверхности `#232326`, интерфейсный accent `#0077FF`, белые selected chips, базовый шаг 4 px и минимум линий. Цвета дорожек остаются функциональными маркерами слоёв и не конкурируют с системными действиями. Lucide-иконки берутся из kernel.
