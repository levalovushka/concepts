# Верстак — references

## Продуктовые паттерны

- ВКонтакте: знакомая грамматика социальной ленты, предметных обсуждений, профиля и создания публикации.
- Apple Human Interface Guidelines — Privacy: разрешение следует за жестом, который объясняет немедленную пользу.
- Apple Human Interface Guidelines — Navigation and tab bars: четыре корневых раздела остаются стабильными, вложенные задачи закрываются возвратом по IA.

## Решения

Продукт не копирует универсальный контентный feed: каждый объект показывает станок, работу, физическую зону и текущий статус. Расписание привязано к операции, проект хранит передачу и бронь, профиль собирает системные интеграции. Геопозиция, камера, речь, контакты и ATT никогда не запрашиваются на старте.
