## Review route

Тестовый номер `+7 900 000-00-00`, пароль `review2026`; гостевой вход доступен. Базовый маршрут: «Станки» → станок → бронь / отметка; «Расписание» → смена; «Проекты» → проект / инструктаж; «Профиль» → интеграции устройства. Каждый ключ и fallback перечислен в сгенерированной матрице `02-architecture.md`.

Карточка стора — третья сверка концепта: App Store, Info.plist и privacy-лейблы обязаны говорить одно и то же. Источник значений — блок `appStore` в `concept.json`; лимиты (Name 30 / Subtitle 30 / Promotional Text 170 / Keywords 100) проверяет `lint-concept.mjs`.

Обязательно: демо-доступ для ревьюера (тестовый номер и пароль) и Review Notes, в которых для каждого доступа сказано, каким жестом ревьюер до него дойдёт.
