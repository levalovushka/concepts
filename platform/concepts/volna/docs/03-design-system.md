# Волна — design system

- Типографика: Inter Medium для заголовков и действий, шкала 11/12/13/14/19/22/31 pt; служебные метаданные не мельче 11 pt.
- Сетка: 16/18/24 pt по типу поверхности; 10–12 pt внутри плотных строк.
- Цвет: нейтральные светлые root-экраны, фиолетовый accent `#6558F5`, тёмный immersive player.
- Медиа: фотографии без текста и логотипов; разный масштаб hero/mosaic/list/player.
- Иконки: только Lucide-спрайт ядра; icon-only controls имеют `aria-label`.
- Границы: только для системных групп и progress; основное разделение дают отступ, тон и масштаб.
