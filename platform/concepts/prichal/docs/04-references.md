# Причал — references

## Продуктовые паттерны

- ВКонтакте: социальная лента знакомого круга, предметные обновления, сообщества-лодки и профиль участника.
- Apple Human Interface Guidelines — Privacy: доступы появляются только в момент съёмки, проверки места или подключения интеграции.
- Apple background execution patterns: системные возможности ограничены однонаправленным статусом конкретного выхода и имеют наблюдаемое состояние.

## Отстройка

Вместо бесконечной ленты главная показывает ближайший выход. «Журнал» содержит только проверяемые бортовые факты и операционные обновления, а «Флот» группирует социальный контекст вокруг лодок.
