# Причал — design system

## Визуальный язык

Основные рабочие экраны используют белую поверхность, тёмно-синий текст `#122832` и спокойный вторичный `#687D87`. Сигнальный жёлтый используется только для ближайшего действия и предупреждения. Глубокий navy `#071C26` зарезервирован для записи, медиаплеера, однонаправленного live-статуса, виджета и lock-screen — только там тёмный фон объясняется контекстом.

Manrope используется для контента, IBM Plex Mono — для времени, ветра, координат и статусов. Минимальный текст — 11 px, hit target — 44 pt. Радиусы 12–14 px и тонкие границы отделяют интерактивные группы на общей светлой поверхности.

Ключевые компоненты: карточка следующего выхода, маршрут, crew-stack, бортовой факт, журнал узла, радар точки сбора, recorder, audio player, однонаправленный live-статус, виджет и системные settings rows.
