**Category:** Social Networking / Lifestyle

## Promotional text

Ближайшие выходы, свободные места и состояние лодки — одной короткой записью для тех, кто идёт следом.

## Review route

Тестовый номер `+7 900 000-00-00`, пароль `review2026`; гостевой вход доступен. Маршруты: «Выходы» → запись / карточка выхода; «Флот» → лодка → журнал; «Журнал» → оповещения; «Профиль» → устройство. VoIP проверяется через действие «Получать статус без задержки» на выбранном выходе; это однонаправленный статус без звонка и голосового ответа.

Карточка стора — третья сверка концепта: App Store, Info.plist и privacy-лейблы обязаны говорить одно и то же. Источник значений — блок `appStore` в `concept.json`; лимиты (Name 30 / Subtitle 30 / Promotional Text 170 / Keywords 100) проверяет `lint-concept.mjs`.

Обязательно: демо-доступ для ревьюера (тестовый номер и пароль) и Review Notes, в которых для каждого доступа сказано, каким жестом ревьюер до него дойдёт.
