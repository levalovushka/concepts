UI

Экраны, tab bar, nav stack, system ask, snackbar. Только отображение — статусы доступов не хранит.

Domain

Земляк · город · место · период жизни · публикация · обсуждение · встреча · выпуск эфира.

Services

Permissions · EmailAuth · Feed · Messages · Calls · LocalPlaces · Audio · Cast · BackgroundTasks.

Data

CoreData — своё. Keychain — токен входа. FileManager — файлы пользователя. Статический контент-пак только на чтение. Своего бэкенда нет.

External

CDN контент-пака · SDK входа по почте · остальные SDK, если они реально в сборке.
