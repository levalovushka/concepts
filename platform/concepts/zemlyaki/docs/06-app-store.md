# Земляки — app-store

Primary category — Social Networking, secondary — Lifestyle. Название и описание обещают ленту земляков, обсуждения, сообщения, местный эфир и встречи; они не заявляют официальные городские услуги или скрытые функции.

Карточка стора — третья сверка концепта: App Store, Info.plist и privacy-лейблы обязаны говорить одно и то же. Источник значений — блок `appStore` в `concept.json`; лимиты (Name 30 / Subtitle 30 / Promotional Text 170 / Keywords 100) проверяет `lint-concept.mjs`.

Обязательно: демо-доступ для ревьюера (тестовая почта и код) и Review Notes, в которых для каждого доступа сказано, каким жестом ревьюер до него дойдёт.

Демо-аккаунт использует тестовую почту и принимает любой четырёхзначный код без отправки письма. В данных уже есть 23 земляка, публикации, обсуждения, длинная запись эфира, видео и встреча. Review Notes из `concept.json` дают путь до каждого условного доступа за 2–3 тапа и отдельно называют fallback. Privacy labels согласованы с функциями: контакты сопоставляются локально; precise location используется для места и временных отметок дороги; IDFA передаётся рекламному SDK только после ATT; пользовательский контент хранится у подключённого провайдера.

## Актуальная серия кадров

1. `city` — Узнавайте город заново
2. `object` — Собирайте историю каждого места
3. `places` — Сохраняйте знакомые места
4. `passport` — Покажите свою точку на карте
5. `live` — Слушайте городской эфир

Серия пересобирается из текущих продуктовых экранов; удалённые поверхности не входят в экспорт.
