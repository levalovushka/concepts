# Земляки — quality evidence

## Продуктовая самостоятельность

- `city`: состояние районов → событие → адресные объекты на временной оси, а не авторский social-feed skeleton.
- `passport`: родная точка → timeline мест → локальный граф → вклад по адресу, а не универсальный профиль со статистикой постов.
- `places`: главный уникальный экран — интерактивный граф дома, школы, вокзала и улицы.
- `topics`: городские задачи сгруппированы по месту и статусу подтверждения.
- `meetup`: карта точки, статусы прибытия, маршрут и логистика вместо event hero со списком людей.
- `object`, `live`, `archive`: материалы индексируются адресом, эпохой и местом; повторяющиеся декоративные обложки не используются.

Из 31 screen ID с `Rodnya` совпадают только шесть системных/общеплатформенных: `phone`, `code`, `codefail`, `call`, `settings`, `invite`. Грамматика ОК сохранена через пять вкладок, отдельные темы и сообщения, оранжевые действия, зелёные статусы, тёплые поверхности и публичные реакции.
