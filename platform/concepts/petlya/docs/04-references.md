# Петля — референсы паттернов

> **Статус:** прогон по Mobbin MCP для этой предметной области **не выполнен** — коннектор требует авторизации и в текущей сессии недоступен. Прошлое исследование было про короткое вертикальное видео (лента, action rail, камера) и к «Петле» не применимо: оно удалено, чтобы не тянуть за собой чужой визуальный язык. Ниже — паттерны, на которые опирался прототип, и список того, что нужно проверить по Mobbin, когда доступ появится.

---

## На какие паттерны опирается прототип

### Урок: видео сверху, материал снизу

Закреплённый плеер и скроллящийся контент под ним — паттерн обучающих приложений (Duolingo-подобные уроки, Skillshare, Apple Fitness+). Ключевое отличие «Петли»: под видео не описание и не комментарии, а **схема**, с которой человек сверяется прямо во время просмотра.

**Взято:** плеер фиксированной высоты, скраб-бар и таймкоды внутри видео, действия под плеером отдельной полосой.
**Не берём:** вкладки «Описание / Материалы / Обсуждение» — это лишний уровень, схема должна быть сразу.

### Ряд действий под плеером

Крупные тап-цели вместо иконок в углу видео. Причина продуктовая: у пользователя заняты руки, и промахиваться по 24-пиксельной иконке он не должен. Отсюда `.chip-act` высотой 56pt на всю ширину, а не rail из мелких иконок.

### Bottom sheet для устройств и счётчика

Стандарт iOS для выбора устройства воспроизведения (системный AirPlay picker, Google TV, Spotify Connect). Sheet не уводит с урока и возвращает в него по grabber’у.

**Взято:** grabber, затемнённая подложка, список устройств строками, основной CTA внизу.

### Now Playing на локскрине

Системная поверхность, не кастом. Обязательна при `UIBackgroundModes: audio` — без заполненного `MPNowPlayingInfoCenter` и remote-команд это прямой отказ на ревью.

**Взято:** артворк, название урока, курс во второй строке, ±15 секунд вместо «предыдущий / следующий трек» — для урока перемотка полезнее переключения.

### Grouped-списки для проектов и профиля

Родной iOS Settings-паттерн: `.ios-list` с радиусом 12, вставками 16pt, заголовками секций 13pt. Ничего не изобретаем — экран профиля должен выглядеть как системный.

### Сканирование этикетки

Паттерн `DataScannerViewController`: затемнённый кадр, уголки рамки на распознанной области, карточка с распознанными полями снизу. Так работают сканеры документов и QR в системных приложениях.

**Взято:** уголки рамки, подсказка над кадром, карточка результата с ключ-значение, единственный CTA. Плюс выход на случай неудачи под CTA — как «Ввести данные вручную» в сканерах карт и документов.

### Сохранение ссылки из интернета

Паттерн read-it-later (Pocket, Instapaper, «Избранное» в Telegram) и импорт по ссылке в приложениях-компаньонах: система отдаёт URL, приложение показывает **превью из разметки самой страницы** и одну кнопку сохранения. Ничего не скачивается — сохраняется ссылка.

**Взято:** URL строкой mono сверху, крупная карточка-превью с заголовком и источником, выбор «куда положить», один акцентный CTA и тихий выход «открыть в источнике».

### Поиск мест на карте

Паттерн Apple Maps / Yelp: карта сверху, строка запроса под ней, список результатов с расстоянием. Расстояние показывается **только** при доступе к геопозиции — иначе список сортируется иначе и расстояний в нём нет.

### Голосовой счётчик

Прямого массового референса нет — ближайшие аналоги вне iOS-мейнстрима: кликеры для вязания и голосовые счётчики повторений в фитнесе. Решение собрано из системных примитивов: крупная цифра (как таймер в «Часах»), индикатор «Слушаю» с волной (как диктовка), кнопки ± как запасной путь.

## Чего сознательно избегаем

- Иконки-эмодзи в интерфейсе.
- Второй акцентный цвет: teal `#0d8a7a` — единственный.
- Градиентные кнопки, glow, скругления больше 22pt на контенте.
- Кастомный таб-бар: только системный вид с blur.
- «Уютная» стилизация под рукоделие — засечки, крафтовая бумага, вязаные шрифты. Хром остаётся системным, тепло даёт медиа.

## Что проверить по Mobbin, когда появится доступ

Список конкретных запросов, чтобы прогон не превратился в блуждание:

| Что искать | Зачем |
|---|---|
| Course / lesson player (Skillshare, MasterClass, Coursera) | Сверить компоновку «видео + материал», высоту плеера, поведение при скролле |
| In-app Cast / device picker | Убедиться, что sheet устройств совпадает с ожиданием пользователя |
| Row counter / rep counter | Единственная фича без надёжного референса — нужен внешний взгляд |
| Project tracker (Ravelry, крафтовые трекеры) | Структура карточки проекта: прогресс, материалы, заметки |
| Document / label scanner | Сверить рамку сканирования, карточку результата и путь «ввести вручную» |
| Read-it-later / save-link (Pocket, Instapaper) | Превью по ссылке и список отложенного |
| Maps place search | Строка запроса над списком и поведение расстояний без геодоступа |
| ATT pre-prompt | Формулировки и вёрстка экрана-объяснения перед системным алертом |

Отдельно стоит посмотреть **Ravelry** и локальные приложения для вязания: это прямые конкуренты по дневнику проекта, и важно понять, чего они не делают с видео и счётом рядов.
