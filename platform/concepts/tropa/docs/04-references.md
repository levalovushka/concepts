# Референсы и решения

| Источник | Наблюдение | Решение в «Тропе» |
|---|---|---|
| Apple Human Interface Guidelines — Privacy | Системный запрос появляется после понятного действия | Ни один доступ не спрашивается на входе; у каждого есть подписанная кнопка и fallback на его экране |
| Apple Background Tasks | Фоновая работа не запускается по точному расписанию | Экран «Фон и сезон» показывает свежесть, очередь и ручное обновление |
| Apple Local Network Privacy | Локальная сеть оправдана поиском и соединением устройств рядом | Сверка планов открывается только на точке сбора; QR остаётся альтернативой |
| iOS grouped settings | Системные настройки читаются как однородные строки | Privacy, alerts, background и security используют единый grouped row и toggle |

Заимствованы только узнаваемые паттерны социальной сети: хронологическая лента объектов, профиль вклада и создание записи. Содержательная отстройка — маршрут, точка и структурированная передача задачи вместо разговорной поверхности.
