# Сеанс — визуальный аудит

Фаза 8: PNG всех 22 экранов, каждый просмотрен в полный размер. Ниже — то, что нашлось и что с этим сделано. Серьёзность: **блокер** — экран сломан, **заметно** — видно с первого взгляда, **придирка** — заметно только рядом с исправленным вариантом.

## Первый проход

| Экран | Что не так | Серьёзность | Как починено |
|---|---|---|---|
| `clips` | Таб-бар всплыл под статус-бар: весь контент экрана абсолютный, и таб-бар остался единственным элементом потока | **блокер** | `.se-clips > .tabbar { margin-top: auto }`, правило с комментарием в `styles.css` |
| `clips` | Мета-строка клипа и подпись «Снять» уходили под таб-бар: отбивка считалась от `--tab-h` без safe-area | **блокер** | `bottom: calc(var(--tab-h) + var(--safe-bottom) + 14px)` для `.se-clip-body` и `.se-clip-acts` |
| `record` | Заголовок камеры «Клип с показа · 0:22 из 0:30» наезжал на плашку «ЗАПИСЬ» в правом слоте | **блокер** | Заголовок сокращён до «Клип с показа», время ушло в плашку записи |
| `hall`, `scan`, `clips`, `join` | Моноширинный стоял на целых фразах: «0:14 · слышат все 14 наушников», «код 41-90-27 · зал на 18 мест», «каждые 2 с» — слова разъезжались | заметно | `.se-num` обёрнут только вокруг чисел; в сводке синхронизации значение сокращено до «2 с» |

| `cast` | Под шитом чёрный ничей кусок вместо затемнённой записи — «провал подложки» из таксономии фазы 8 | заметно | Слой `.se-under`: кадр записи и её название под затемнением |
| `ads` | Кнопки не прижимались к низу, под ними оставалось 140 px пустоты: `.push` из ядра работает только внутри флекс-колонки, а `.body-scroll` ею не является | заметно | Модификатор `.se-scroll.se-fill` с `display: flex` |
| `venue` | Строка следующего показа ломалась в шесть строк: кадр 106 px, плашка «через 40 мин» и три строки текста не помещались | заметно | Плашка сокращена до «40 мин», мета переразложена: время и тапёр в одной строке, места и вход — в другой |
| `background` | Подпись «Экран можно не трогать до конца сеанса» — авторский голос на локскрине, которого в iOS не существует | заметно | Убрана вместе с классом `.se-lock-hint` |
| `pick` | Блок «Что уходит на площадку: приложение не читает всю медиатеку — выбор отдаёт системный PHPicker» — интерфейс объяснял сам себя | заметно | Убран целиком; требования площадки остались как данные |
| `shows` | «Программу объявят 17-го» переносилось по дефису: «17-» и «го» на разных строках | придирка | «Программу пока не объявили» |
| `nearby`, `talk`, `pick` | Заголовок секции ломался о правую подпись в две строки | придирка | Сокращены правые подписи и один заголовок |

Плюс 16 замечаний машинного аудита по кеглю: `.se-badge`, `.se-crest.sm`, `.se-dist span`, `.se-date span`, `.se-rec-pill` были 10 px против минимума 11. Все поднялись до 11/14; марка площадки в клипе выросла с 26 до 28 px, чтобы буквы не жались.

## Второй проход

Прогнан после всех правок. Одна придирка: на `search` заголовок «Люди, которые играют» ломался о правую подпись — стал «Кто играет». Дефектов серьёзнее нет. Что осталось и сознательно оставлено:

- **Названия в строках с кадром переносятся на вторую строку** (`saved`, `search`, `venue`). Кадр 106 px и значение справа оставляют тексту около 150 px. Так выглядят и настоящие списки видеосервисов; сокращать названия фильмов ради одной строки — хуже.
- **Воздух между кнопкой и следующей секцией** на `venue` и `hall` около 60 px: сумма отбивки `.cta-col` из ядра и `.se-sec`. Трогать одну из двух величин ради одного экрана значило бы разъехаться с остальными.

- **Чип «С тапёром» обрезан правым краем** на `home`. Это горизонтальный скроллер, и обрезанный элемент — признак того, что список продолжается; в iOS так и рисуют.
- **Кадр `.ph` в плеере `film` перекрыт кнопкой воспроизведения**. Иконка плейсхолдера и кнопка стоят в одном центре. Ставить их вразнобой значило бы двигать системный контрол.
- **Локскрин `background` пуст ниже Now Playing.** Так выглядит настоящий локскрин: карточка воспроизведения и часы, больше ничего.

## Чем проверено

```bash
npm run build -- seans && npm run shots -- seans && npm run build -- seans \
  && npm run test -- seans && npm run lint -- seans && npm run audit -- seans
```

- `test` — **47/47**, зелёный.
- `lint` — расхождений нет.
- `audit` — чисто.

Разметки экранов 110 КБ на 22 экрана — плотность на уровне самого большого концепта репозитория, а не слайдов.

## Что не проверено

- **Похожесть на целевое приложение.** Скриншотов ВК Видео в работе не было; сходство выведено из токенов набора VK-типа и общей раскладки видеосервисов. Подробности и способ доделать — в [04-references.md](04-references.md).
- **Гарнитура на устройстве.** `Golos Text` и `Roboto Mono` подтянуты из Google Fonts (проверен ответ 200 и наличие `@font-face`), но кегли сверялись на отрендеренных PNG в Chromium, а не на iPhone.
