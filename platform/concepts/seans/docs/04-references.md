# Сеанс — референсы паттернов

Задача концепта нетипична для репозитория: он должен **попадать в категорию целевого приложения и быть на него похожим**, а не отстраиваться от него. Поэтому источников два, и первый важнее второго.

## Откуда взято сходство

**Первый источник — набор VK-типа**: `Base Kit/vk-style-visual-guide.en.md` и `design-tokens.json`. Значения в нём вытащены из Figma-переменных VKUI программно, а не сняты на глаз, поэтому опираться на них можно как на спецификацию. Взята тёмная часть набора (§11): страница темнее блоков, разделитель `rgba(255,255,255,.10)`, скругление контрола 10, карточки 16, плотность ячейки 16/20, статусные цвета как есть.

**Второй источник — системные паттерны iOS** (HIG, `kernel/ios-chrome.md`): permission-алерт, снекбар, статус-бар, локскрин с Now Playing, сканер кода, камера, sheet с грабером, таб-бар и вход по номеру берутся оттуда и не перерисовываются.

## Чего сделать не удалось — и это важно для оценки сходства

**Экраны ВК Видео не разобраны.** Скриншотов целевого приложения в работе не было, поэтому сходство держится на токенах набора и на общей раскладке видеосервиса, а не на сверке с конкретными экранами. Что проверено:

- **Mobbin** — прогон выполнен, запрос «VK Video home feed with video thumbnails and clips», iOS. **ВК Видео в базе нет**: вернулись [Taobao](https://mobbin.com/screens/14b8b817-e24c-41cb-8d98-de343e868a31), [TikTok](https://mobbin.com/screens/82e30763-fa1e-46bb-b354-813d032332f5), [NAVER](https://mobbin.com/screens/7ca05a3a-9dfb-424b-8287-c2c61dae3ab7), [CapCut](https://mobbin.com/screens/f1dc66e2-f4a2-46f4-b432-53f3e198d577), [Sora](https://mobbin.com/screens/594d8ce3-47ba-49e9-8656-ec79ba8e0763), [LINE](https://mobbin.com/screens/f3a4378f-f837-4816-995e-def09be8cf8e). Годится для общей раскладки видеофида и вертикальных клипов, не для сверки с целевым приложением. То же самое было с ВК Музыкой у предыдущего концепта — базы Mobbin по продуктам VK нет.
- **Категория проверена**: «Развлечения» — там целевое приложение стоит первым в чарте российского App Store. Категория карточки стора выставлена по этой проверке, а не по догадке.

**Что это значит.** Утверждение «выглядит похоже» здесь непроверенное: похожесть выведена из спецификации набора и из того, как устроены видеосервисы вообще. Если нужен более точный слепок — пришлите скриншоты ВК Видео (главная, страница видео, клипы, «Моё»), и вёрстка сверяется с ними за один проход.

## На какие паттерны опирается прототип

| Паттерн | Где применён | Откуда взят |
|---|---|---|
| **Тёмная страница темнее блоков** | все экраны приложения | Base Kit §11: `background.page` темнее `background.content` |
| **Cell / Rich Cell** — ведущий элемент, заголовок с подписью, значение справа | все списочные экраны (`.se-row`) | Base Kit §6 |
| **Плотность 16/20** в ячейке вместо системных 17/22 | `.se-t1` / `.se-t2` | Base Kit §3, Headline 1 / Text |
| **Hairline `separator.primary`** между ячейками, перед первой строкой разделителя нет | те же списки | Base Kit §6 Separator |
| **Group Header + «Показать все»** | все секции (`.sec-head` / `.sec-more` из ядра) | Base Kit §6 |
| **Content Badge** — цветной текст-чип статуса | `.se-flag`: «идёт», «перенесён», «догоняет», «нет записи» | Base Kit §6, Badge |
| **Скругление контрола 10, карточки 16** | кнопки, чипы, блоки | Base Kit §5 |
| **Кадр 16:9 с длительностью в правом нижнем углу** | герой, лента, строки списка | общая раскладка видеосервисов (в том числе результаты Mobbin выше) |
| **Горизонтальная лента под заголовком секции** | «Продолжить», «Дорожки без картинки», «Клипы» (`.hscroll` ядра) | Base Kit §6 + видеофиды |
| **Вертикальный клип во весь экран с правым столбцом действий** | `clips` | TikTok / CapCut из выдачи Mobbin; в клипе действия сведены к трём, потому что лайков и комментариев в концепте нет |
| **Мини-плеер над таб-баром** | `home` (`.miniplayer.on-dark` ядра) | Base Kit + аудиоплееры |
| **Сегментированные разделы с подчёркиванием** | `saved`: Всё · Клипы · Дорожки (`.segbar.on-dark` ядра) | Base Kit §6 |
| **Чипы-фильтры над фидом** | `home` (`.se-chips`) | Base Kit §6 |
| **Стат-ряд колонками с хайрлайнами сверху и снизу** | `session`, `film`, `venue`, `profile` (`.se-stats`) | Base Kit §9, Profile |
| **Permission-алерт, снекбар с путём в «Настройки»** | все экраны с доступами (из ядра) | iOS HIG, `kernel/ios-chrome.md` |
| **Now Playing на локскрине** — обложка, две строки, полоса, три контрола | `background` (`.se-np`) | iOS, `MPNowPlayingInfoCenter` |
| **Сканер кода** — затемнение вне рамки, найденный объект карточкой снизу | `scan` (`.se-frame`, `.se-found`) | `DataScannerViewController` |
| **Камера с записью** — прогресс записи, шаттер, миниатюра | `record` (`.cam-*`, `.progress-rec` ядра) | iOS |
| **Сетка медиатеки 3 в ряд с обводкой выбранного** | `pick` (`.se-grid`) | `PHPicker` |
| **Сводка синхронизации** — поправка, расхождение, число устройств | `join`, `background` (`.se-sync`, `.se-np-foot`) | **не из набора и не из мобильных продуктов**: ближайший аналог — служебные панели Sonos и Dante. Задачи «показать расхождение двадцати телефонов с проектором» в видеосервисах не бывает |
| **Уровень голоса полосами** | `hall`, `talk` (`.se-level`) | диктофоны iOS и пульты трансляции |

## Что осознанно не копируем

| Что | В первоисточнике | У нас | Почему |
|---|---|---|---|
| **Лайки, комментарии, репосты под видео** | полный ряд действий | нет | UGC вырезан на фазе 4: без бэкенда чужих данных и модерации не будет |
| **Подписки на людей и авторов** | канал автора, аватар, счётчик | подписка только на площадку | Учётной записи в концепте нет, есть номер; людей показываем именами в данных, а не профилями |
| **Аватары** | круги с фото | нет | Ни одного лица в интерфейсе: марка площадки — две буквы на тихой подложке |
| **Ряд сторис** | круги с акцентным кольцом | нет | Чужого контента в приложении нет |
| **Раздел покупки и подписки** | тарифы, платный контент | нет | Цифрового товара внутри нет, 3.1.1 не задействован |
| **Ссылки на видео вне приложения** | Universal Links | нет | Правило платформы: диплинков не делаем, ключ не заявляем |
| **Брендовая капсула в строке статус-бара** | пилюля со знаком | вордмарк отдельной строкой под статус-баром | Строку статус-бара рисует ядро; изображать в ней элемент приложения нельзя |
| **Пятнадцать акцентных цветов** | палитра статусов | один акцент + оранжевый как статус | Правило платформы: второй акцент запрещён |
| **Тёмная и светлая темы разом** | два набора токенов | тёмная, кроме входа по номеру | Страница итогового файла залочена в светлую; внутри устройства тема одна |
| **Swipe actions на ячейках** | есть | нет | Прототип статичный, жест на PNG не проверяется — значит не заявляется |
| **Иллюстрации и стоковые фото** | обложки видео | плейсхолдер `.ph` на 12 экранах из 22 | Правило платформы: визуал не делаем |

## Что проверить, когда появятся экраны целевого приложения

| Что искать | Зачем |
|---|---|
| Главная ВК Видео: порядок секций, высота кадра, что стоит первым | `home`: сейчас порядок выведен из логики продукта, а не сверен |
| Страница видео: где кнопки ТВ и загрузки, как показаны дорожки | `film`: расположение контролов над кадром взято из общей практики |
| Клипы: что в правом столбце и сколько там элементов | `clips`: у нас три действия вместо пяти-шести |
| Раздел «Моё»: как показаны загрузки и их состояния | `saved`: состояния загрузки взяты из ядра (`.dl`) |
| Экран входа VK ID | `phone` / `code`: разметка входа общая для всех концептов, но сверить кегли стоит |
| Приложения синхронного просмотра (Silent Disco, Sennheiser MobileConnect, Listen Everywhere) | `join` и `hall`: как показывают задержку, дрейф и выбор канала — это ближайшие родственники по механике |
