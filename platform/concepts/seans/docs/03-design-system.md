# Сеанс — дизайн-система (концепт)

Видеосервис в категории «Развлечения». Задача здесь обратная той, что решали предыдущие концепты репозитория: не отстроиться от первоисточника, а **попасть в его категорию и в его манеру** — это условие задачи, поставленное заказчиком. Отстройка от целевого приложения идёт не по вёрстке, а по предметным компонентам: точка показа в локальной сети, дорожки, расхождение тайм-кода, уровень микрофона.

Визуальный язык взят из набора VK-типа (Base Kit: `vk-style-visual-guide.en.md` + `design-tokens.json`), тёмная часть — §11. Системный iOS-хром (статус-бар, permission-алерт, снекбар, sheet с грабером, локскрин, камера, свитч, home indicator, компоненты входа по номеру) берётся из ядра **без единой правки**. Иконки — из спрайта Lucide (`kernel/icons.svg`), своих SVG-путей в экранах нет.

---

## Направление

**Тёмный видеосервис.** Страница темнее блоков — как в первоисточнике (`background.page` темнее `background.content`), а не наоборот. Кадр всегда 16:9 с плашкой длительности в правом нижнем углу; лента — горизонтальная; клипы — вертикальные во весь экран; над таб-баром мини-плеер из ядра.

Разделение поверхностей:

- **Тёмная страница** (`.se-page`, `#121317`) — **15 экранов**, посчитано грепом по `screens/*.html`: `ads`, `home`, `nearby`, `search`, `film`, `session`, `join`, `hall`, `curator`, `talk`, `pick`, `shows`, `venue`, `profile`, `saved`.
- **Чёрные системные** — **4 экрана**: `scan` и `record` (камера, `.cam-*` из ядра), `clips` (клип во весь экран), `cast` (шит поверх затемнённой записи — под ним `.se-under` с тем же цветом страницы).
- **Локскрин** — `background`: `.lock-bg` из ядра с градиентом в синеву, Now Playing на `backdrop-filter`.
- **Светлые** — **2 экрана**: `phone` и `code`. Разметка входа по номеру копируется из концепта в концепт без изменений, поэтому она остаётся белой. В первоисточнике вход тоже светлый, так что разрыв не выдуман.

Один акцент на весь продукт: синий `#3E8BFF`. Им красятся первичная кнопка, активный радиопереключатель, полоса воспроизведения, плашка «через 40 минут», ссылка «Показать все», подпись «Предложить своё видео» и точка «вы в зале». Второго акцента нет. Оранжевый (`#F8A01C`) — не акцент, а единственное статусное значение: плашки «перенесён», «догоняет», «проверить звук» и подложка fallback'ов при отказе.

Избегаем: капсульных кнопок Apple (`--r-btn` внутри `.screen` переопределён в 10px — значение первоисточника), large title, разделителей внутри карточки, теней как высоты, эмодзи в интерфейсе, аватаров людей.

## Токены

Значения — из `:root` в `concepts/seans/styles.css`.

### Цвет

| Токен | Hex | Где |
|---|---|---|
| `--se-page` | `#121317` | тёмная страница |
| `--se-card` | `#1D1F25` | блок на странице: герой, панель, сводка синхронизации, живой микрофон |
| `--se-quiet` | `#262931` | тихая поверхность: чип фильтра, ведущая иконка строки, марка площадки, поле поиска, плашка даты |
| `--se-ink` | `#FFFFFF` | основной текст |
| `--se-sub` | `#A7AEB9` | второстепенный: лид, подпись под названием, значения в сводке. 7,4:1 на странице |
| `--se-mute` | `#8A919C` | третичный: мета-строки списка, кикер, значение секции. 5,0:1 на странице |
| `--se-dim` | `#6C737E` | выключенное: недоступная строка, правовая строка, шеврон |
| `--se-line` | `rgba(255,255,255,.10)` | разделитель между строками, рамки сводок |
| `--se-red` | `#FF3347` | «Выйти из зала», «Удалить скачанное», точка записи микрофона |
| `--se-green` | `#4BB34B` | заведён под положительный статус |
| `--se-warn` | `#F8A01C` | статусные плашки и подложка fallback'а |
| `--se-r-card` | `16px` | карточка и блок |
| `--se-r-ctl` | `10px` | кнопка, чип, поле — значение первоисточника |
| `--se-r-tile` | `12px` | кадр в горизонтальной ленте |

Три значения — `#FF3347`, `#4BB34B`, `#F8A01C` — взяты из набора как есть: это статусные цвета, отстраивать их бессмысленно. Шкала серых отошла от первоисточника в одном месте и намеренно: `icon.secondary` `#99A2AD` на тёмной странице даёт достаточный контраст, но в наборе это цвет **иконки**, а через `--se-mute` идёт почти вся третичная типографика — поэтому тон затемнён до `#8A919C`, чтобы мета не спорила с заголовком строки.

Акцент приходит из ядра, а не из `:root` концепта — его подставляет сборка из блока `brand` в `concept.json`: `--accent-fill: #3E8BFF`, тёмный вариант хрома страницы `#7FB2FF`. Внутри экранов используется только `var(--accent-fill)`.

Производные акцента заданы литералами (нужны альфа-варианты, которых в токенах нет): `rgba(62,139,255,.16)` — тинт панели ATT, `rgba(62,139,255,.18)` — тинт живой иконки строки и плашки «играет», `#8FBAFF` — текст и глиф на этих тинтах, `rgba(255,255,255,.05)` — подложка выбранной строки.

## Три ловушки CSS

Все три учтены по построению, а не после падения:

1. **Коллизия имён.** Свой префикс `se-`; в `base.css` такого префикса нет.
2. **Шорткат `background`.** Не используется ни разу — только `background-color`.
3. **Шорткат `margin`.** Не используется — только `margin-top` / `margin-bottom` / `margin-left` / `margin-right`, иначе гасятся утилиты `.mt*` из ядра.

Плюс четвёртая, найденная на этом концепте: **таб-бар на экране с абсолютным содержимым**. У `clips` весь контент лежит в `position: absolute`, и `.tabbar` — единственный элемент потока: без `margin-top: auto` он всплыл под статус-бар. Видно только на PNG.
