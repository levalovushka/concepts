# Сеанс — карточка App Store

Карточка стора — третья сверка концепта: App Store, Info.plist и privacy-лейблы обязаны говорить одно и то же. Источник значений — блок `appStore` в `concept.json`; лимиты (Name 30 / Subtitle 30 / Promotional Text 170 / Keywords 100) проверяет `lint-concept.mjs`.

## Описание

Текст описания — в `appStore.description`. Структура: первый абзац отвечает, что это и для кого, дальше по блоку на фичу, и это ровно те фичи, которыми заслужены доступы из набора:

1. **ЗВУК В НАУШНИКАХ** — Local Network + Background Audio.
2. **ЖИВОЙ ГОЛОС КУРАТОРА** — Microphone.
3. **ЗАПИСИ И ДОРОЖКИ** — Background Audio, загрузки.
4. **ПЛОЩАДКИ РЯДОМ** — Location + Push.

## Скриншоты и превью

Порядок кадров = порядок ценности, не порядок навигации:

1. `hall` — вы в зале: что идёт, какая дорожка, расхождение с проектором.
2. `background` — экран погас, дорожка играет, Now Playing заполнен.
3. `join` — точки показа в локальной сети и выбор дорожки.
4. `home` — показ сегодня и записи прошедших.
5. `talk` — микрофон куратора и уровень голоса.
6. `nearby` — площадки рядом.

Превью не делаем: анимации в концепте нет.

Единственная строка с трекингом сходится с наличием `NSUserTrackingUsageDescription` в наборе — это линтер проверяет отдельно. Голос куратора помечен как аудио, но не как связанный с пользователем: он идёт в наушники зала по локальной сети и сохраняется только в дорожку показа, если организатор оставил соответствующий переключатель включённым.

## Демо-доступ для ревьюера

| Поле | Значение |
|---|---|
| Номер | +7 900 000-00-00 |
| Код | 0000 |

Тестовый номер принимает код 0000, SMS не отправляется. **Точка показа в демо объявляется самим приложением на этом же устройстве**, поэтому подключение к залу, выбор дорожки и микрофон куратора проверяются без второго телефона и без выезда на площадку.

## Review Notes

Первый экран — вход по номеру, дальше один экран про рекламу, дальше приложение. Промптов на старте нет ни одного.

| Доступ | Каким жестом ревьюер до него дойдёт |
|---|---|
| `NSLocalNetworkUsageDescription` | Главная → карточка показа → **«Найти точку показа»**. Дальше список найденных точек, выбор дорожки, вход в зал. Тот же ключ второй раз: запись показа → иконка телевизора над кадром |
| `UIBackgroundModes: audio` | Зал → **«Погасить экран»**. Дорожка продолжает играть, Now Playing заполнен, работают пауза и ±15 с |
| `NSMicrophoneUsageDescription` | Карточка показа → **«Я провожу этот показ»** → **«Взять микрофон»**. Голос уходит в наушники подключённых устройств отдельной дорожкой |
| `NSCameraUsageDescription` | Карточка показа → **«Считать код показа»**. Тот же ключ второй раз: Клипы → **«Снять»** |
| `NSLocationWhenInUseUsageDescription` | Главная → чип **«Рядом»**. Показывает площадки с расстояниями; при отказе остаётся расписание по городу |
| `NSPhotoLibraryUsageDescription` | Карточка показа → строка **«Короткий метр из зала»** → **«Предложить своё видео»**. Выбор отдаёт системный PHPicker |
| `NSPhotoLibraryAddUsageDescription` | Клипы → «Снять» → **«Сохранить в „Фото“»** |
| `aps-environment` | Показы → **свитч «Начало показов»**. Уведомления: за час до начала и при переносе показа |
| `NSUserTrackingUsageDescription` | Второй экран после входа → **«Разрешить и продолжить»**. Промпт идёт только после собственного объяснения; путь «Продолжить без разрешения» оставляет неперсонализированную рекламу |

Что должно реально оказаться в сборке, иначе доступ пустой:

- **Local Network** — Bonjour-сервис `_seans._tcp` в `NSBonjourServices`, обмен тайм-кодом и звуком через `Network.framework`. Плюс `_googlecast._tcp` для вывода картинки на телевизор.
- **Background Audio** — `AVAudioSession` в режиме `.playback`, заполненный `MPNowPlayingInfoCenter`, обработчики `MPRemoteCommandCenter`.
- **Microphone** — `AVAudioEngine`, отдающий поток подключённым устройствам; запись в дорожку показа опциональна и управляется переключателем.
- **Location** — `CLLocationManager` с `whenInUse`, запрос только по нажатию «Рядом».
- **Push** — SDK провайдера (FCM/APNs), topics по подписанным площадкам, отправка из дашборда.
- **ATT** — рекламный SDK в сборке; IDFA передаётся только после согласия, при отказе SDK работает контекстно.

## Ключ набора, который не заявлен

`com.apple.developer.associated-domains` — **не заявляется**. Диплинков в концептах не делаем принципиально: Universal Links, приём чужих ссылок и превью по Open Graph вне области концептов, а заявлять доступ без достижимой фичи в этой же сборке нельзя. Из десяти ключей набора ВК Видео концепт несёт девять; решение по десятому принимает человек.

Отдельно: `webcredentials` не заявлен — пароля в приложении нет, вход по номеру идёт через SDK провайдера.
