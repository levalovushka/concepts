# Узел — локальная mini design system

## Палитра

`--u-bg #F2F3F5` · `--u-surface #FFF` · `--u-text #1D2733` · `--u-muted #6D7885` · `--u-accent #0077FF` · `--u-border #E2E6EB` · success `#197243` · danger `#B42318`.

## Ритм и геометрия

Spacing только 4 / 8 / 12 / 16 / 20 / 24 px. Радиусы: 10 control, 14 card, 18 media. Общий horizontal gutter 12 px; root/nav 16 px; primary action 48 px; row 64 px; icon 44 px; tab bar общий для root.

## Типографика

Display 30/36 700; screen title 22/28 700; section 16/22 700; body 15/21 400; body strong 15/21 600; secondary 13/18 400; caption 12/16 500; button 15/20 600. Сброшены browser defaults h1/h2/h3/p/button.

## Варианты

`u-btn` — основное действие; `u-soft` — secondary; `u-card`, `u-row`, `u-setting` — повторяемые рабочие поверхности. Для социальной части используются `u-post`, `u-post-author`, `u-post-media`, `u-post-actions` и единый круглый `u-avatar`. Метрики компонентов не меняются между экранами.
