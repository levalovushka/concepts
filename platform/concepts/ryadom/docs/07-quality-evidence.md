# Рядом — quality evidence

## Контракт

- positioning: `mimicry`
- reference: `vkontakte`
- UI contract: v3
- исходных экранов: 24
- scenario slices: 8
- reference evidence: 4 связи `pattern → screen → behavior`

## Product critique

Проверены четыре возражения: замена разрозненным каналом клуба, дублирование спортивного трекера, сходство с закрытой группой и слишком узкий размер аудитории. Для каждого в `concept.json` указаны решение и экраны-доказательства.

## Визуальные проходы

Первый проход проверяет клубную семантику и узнаваемость VK-грамматики. Второй — плотность, системные состояния, переходы и целостность сценарных срезов. Итоговые машинные проверки фиксируются сборкой, lint, UX spec, visual audit, grid audit и flow tests.
