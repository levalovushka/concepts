# Хвосты — архитектура

Пять корневых разделов: лента, прогулки рядом, создание, сообщения и профиль. `PermissionsService` — единственная точка запросов; отказ всегда возвращает к рабочей альтернативе. Контент прототипа статический, пользовательские действия локальны, сообщения и APNs заземляются SDK провайдера.
