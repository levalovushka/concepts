# Маршрут — карточка App Store

## Позиционирование

**Name:** Маршрут — дорога своих
**Subtitle:** Живые факты вашего пути
**Primary:** Navigation · **Secondary:** Social Networking · **Age:** 13+

«Маршрут» объединяет людей, которые каждый день едут одной городской дорогой. Перед стартом виден свежий риск, во время совместного выезда слышны предупреждения, после проезда факт подтверждается и передаётся следующему человеку.

## Демо-доступ

- Телефон: `+7 900 123-45-67`
- Пароль: `review2026`
- Дополнительного подтверждения нет.

## Путь ревьюера

1. Войти → Пульс → Оставить факт: Camera, Photos и Location с рабочими fallback.
2. Выезды → ближайший выезд → Начать проверку: VoIP поддерживает только однонаправленный live-статус; Microphone и Speech создают структурированный дорожный факт, background audio озвучивает готовые ориентиры.
3. Маршруты → офлайн-пак: Wi‑Fi Info, Hotspot Configuration, background refresh и BGTask.
4. Профиль → Попутчики: Contacts; Профиль → Аварийная карточка: Face ID.
5. Настройки → Виджет / Логины прокатов / Предложения: App Group, Keychain, Autofill и ATT.

## App Privacy

Почта, публикации, фото, голос и точное местоположение связаны с аккаунтом только для работы продукта. Контакты сверяются локально и не выгружаются. IDFA передаётся рекламному SDK только после согласия ATT; отказ не отключает функции и оставляет общую рекламу.

## Скриншоты

Порядок серии: Пульс → Новый факт → Совместный выезд → Передача риска → Офлайн-маршрут. Он повторяет основной цикл ценности, а не перечисляет доступы.

Карточка стора — третья сверка концепта: App Store, Info.plist и privacy-лейблы обязаны говорить одно и то же. Источник значений — блок `appStore` в `concept.json`; лимиты (Name 30 / Subtitle 30 / Promotional Text 170 / Keywords 100) проверяет `lint-concept.mjs`.

Обязательно: демо-доступ для ревьюера (тестовый номер и пароль) и Review Notes, в которых для каждого доступа сказано, каким жестом ревьюер до него дойдёт.
