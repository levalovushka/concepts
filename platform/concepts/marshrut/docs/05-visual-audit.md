# Маршрут — визуальный аудит

## Критерии полного прохода

Каждый PNG проверяется в полном размере, отдельно от контактного листа: первое визуальное ядро, читаемость текста, сетка, контраст, переполнение, системный chrome, видимость primary action и различимость состояний.

## Поперечные линзы

- Иерархия: на root-экранах первым читается ближайший полезный объект, на detail — сам факт или выезд.
- Типографика: основной текст не мельче 14 pt, технические метки 12–13 pt, длинные названия не перекрывают действия.
- Цвет: оранжевый зарезервирован для риска и действия; тёмные поверхности держат белый текст и светлый акцент.
- Композиция: поля 16 pt, строки одного типа имеют общий левый край, tab bar не перекрывает хвост списка.
- Связность: auth и системные экраны остаются iOS-поверхностями, но используют тот же акцент и лексику маршрута.

## Проверяемые ветки

Camera / Photos / Location / Contacts / Calendar / Face ID / Microphone + Speech / Push / ATT имеют видимый denied-state. Entitlements показывают наблюдаемый результат: виджет, фон, офлайн-пак, именное уведомление, аудиосессию и автозаполнение.

## Запрещённые дефекты

Обрезанный текст, hit target меньше 44 pt, ложный шеврон, inline-иллюстрация вместо `.ph`, таб-бар на push/modal, два primary action, скрытый fallback и разъехавшаяся горизонтальная сетка.
