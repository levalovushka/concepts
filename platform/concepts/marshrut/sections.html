UI

Экраны, tab bar, nav stack, system ask, snackbar. Только отображение — статусы доступов не хранит.

Domain

Маршрут · участок · дорожный факт · совместный выезд · передача риска · райдер.

Services

Permissions · Auth · MapKit · Capture · EventKit · Background · Notifications · Voice room · Credential Provider.

Data

CoreData и FileManager держат офлайн-пак; App Group — снапшот виджета; Keychain — сессию и логины прокатов.

External

Готовые SDK Firebase для входа, данных, файлов и уведомлений; WebRTC-провайдер для комнаты выезда. Своего серверного кода нет.
