# Карточка App Store

**Название:** Стол — партии рядом
**Подзаголовок:** Игры со знакомыми людьми
**Категория:** Social Networking / Entertainment
**Возраст:** 13+

Ревьюер может пройти по предзаполненному телефону и паролю либо использовать гостевой вход. Для проверки голоса открыть Столы → Лесные союзы → Счёт; для background audio — Игры → Лесные союзы → Памятка.

Privacy labels включают номер телефона, пользовательский контент и приблизительное место. Трекинг и покупки не заявлены.
