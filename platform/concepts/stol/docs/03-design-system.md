# Дизайн-система «Стола»

Основная продуктовая грамматика близка к мобильному ВКонтакте: синий акцент `#0077FF`, холодный фон `#EDEEF0`, белые карточки, плотная типографика Manrope, нижняя навигация и строки icon/title/subtitle/chevron.

Предметность добавлена дозированно: тёплое дерево, круглые фишки мест, моноширинные время и счёт. Эти детали не заменяют знакомые социальные паттерны.

Сервисные поверхности — настройки, аккаунт, оповещения, приватность — состоят из белых секционных карточек и системных свитчей. Медиа обозначаются только `.ph`.
