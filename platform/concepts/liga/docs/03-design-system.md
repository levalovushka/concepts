# Дизайн-система «Лиги»

## Тон

Спокойный спортивный продукт без декоративной агрессии. Динамику дают живые кадры, счёт и время; интерфейс остаётся нейтральным и собранным.

## Цвет

- `#F5F5F7` — основной текст на тёмной оболочке;
- `#0A0A0A` / `#1C1C1E` — фон и поднятые поверхности VK Video;
- `#8A8D93` — вторичный текст;
- `#0077FF` — CTA, ссылки, progress и active tab icon;
- `#F5F5F7` с тёмным текстом — selected chips;
- `#FF3347` — только эфир и запись;
- `#207B58` — только успешная синхронизация.

## Типографика

Manrope используется для интерфейса, IBM Plex Mono — только для счёта, времени и числовых статусов. Заголовки плотные, с отрицательным трекингом; вторичный текст не меньше 10 px в макете устройства.

## Радиусы

- 10–14 px — бейджи и небольшие контролы;
- 16–18 px — кнопки и строки с фоном;
- 20–24 px — медиакарточки и самостоятельные поверхности;
- круг только для аватара или play.

## Границы

Бордеры используются только как тихие разделители повторяющихся строк. Карточки не получают обводку одновременно с фоном и тенью.
