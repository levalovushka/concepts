# Визуальный аудит

## Линзы

- **Иерархия:** на `home` первым читается одно быстрое дело, на `decision` — вопрос и цена.
- **Типографика:** адресные метаданные вторичны, но не меньше 12 pt; действия 15–17 pt.
- **Цвет:** зелёный означает принадлежность кварталу, оранжевый — срок, красный не используется декоративно.
- **Композиция:** `resources` использует полку-сетку, `decisions` — плотный реестр, `events` — временную ось.
- **Цельность:** номера адресов, радиус поверхностей и навигация повторяются без превращения экранов в один шаблон.

## Проверенные риски

Обрезка длинных адресов, плотность списка при крупном тексте, контраст тёмных экранов, tab bar только на root, видимость fallback после каждого отказа. Открытых blocker/major нет.
