# Образы — дизайн-система

Нейтральная светлая база, фиолетовый акцент `#6B57E8`, Manrope. Заголовки экранов, секций и карточек набираются начертанием Medium (`500`), основной текст — Regular. Продуктовая грамматика близка мобильной социальной сети: компактный header, отдельные root-вкладки, лента полноширинных постов, списки диалогов и сообществ, профиль с сеткой публикаций. Группировку дают фон, интервалы и масштаб; видимые бордеры используются только там, где без них теряется состояние. Lucide SVG — 24 px, интерактивные области — не меньше 44 px.
