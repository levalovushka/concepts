# Сотки — app-store

Заполняется по PLAYBOOK.md.

Карточка стора — третья сверка концепта: App Store, Info.plist и privacy-лейблы обязаны говорить одно и то же. Источник значений — блок `appStore` в `concept.json`; лимиты (Name 30 / Subtitle 30 / Promotional Text 170 / Keywords 100) проверяет `lint-concept.mjs`.

Демо-вход: номер `+7 900 000-00-00`, пароль `review2026`. Номер и пароль вводятся на отдельных экранах; вход и регистрация необязательны. Для якорных доступов Review Notes дают короткие пути: `Лента → Новое в товариществе → Снять/Из медиатеки`; `Сообщения → Председатель → микрофон/звонок`; `Записи → Собрание правления → Слушать → свернуть`; `Общий альбом → Смотреть на телевизоре`; `Лента → Поездка на ярмарку → Отмечать дорогу`.
