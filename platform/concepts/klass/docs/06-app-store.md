# Наш класс — app-store

Заполняется по PLAYBOOK.md.

Карточка стора — третья сверка концепта: App Store, Info.plist и privacy-лейблы обязаны говорить одно и то же. Источник значений — блок `appStore` в `concept.json`; лимиты (Name 30 / Subtitle 30 / Promotional Text 170 / Keywords 100) проверяет `lint-concept.mjs`.

Демо-вход: `review@nashklass.app`, код `0000`; письмо не отправляется. Вход с Apple ведёт в тот же заполненный 3 «Б». Для якорных доступов Review Notes дают короткие пути: `Лента → Что нового в классе? → Снять/Из медиатеки`; `Сообщения → Светлана Викторовна → микрофон/звонок`; `Записи → Собрание 4 сентября → Слушать → свернуть`; `Альбом класса → Смотреть на телевизоре`; `Лента → Экскурсия 12 сентября → Отмечать дорогу`.
