# Экспедиция — дизайн-система

- Единственный шрифт — Inter, веса 400–800.
- Фон `#F7F5EF`, поверхность `#FFFFFF`, текст `#152019`, вторичный текст `#637067`, основной цвет действия `#23634F`.
- Боковые поля — 16 pt, базовый шаг — 4 pt, минимальная интерактивная высота — 44 pt.
- Карточки группируются фоном, расстоянием и радиусом 12–16 pt; декоративные обводки, тяжёлые тени и капс не используются.
- Поля форм — белые нейтральные поверхности без цветных полос. Основная кнопка использует заливку, вторичная — мягкую нейтральную поверхность.
- Permission fallback расположен рядом с действием. Профиль ведёт к телефону, выходу и отдельному подтверждению удаления.
