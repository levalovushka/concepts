# Архитектура продукта

## Информационная архитектура

Четыре стабильных корневых раздела:

| Раздел | Роль | Главный возврат |
|---|---|---|
| Главная | персональная витрина, продолжение и live | продолжить текущий сет |
| Обзор | поиск, редакционная курация, эфиры и настроения | открыть новое |
| Моя музыка | сохранённые сеты, треки, диджеи и загрузки | вернуться к коллекции |
| Профиль | уведомления, фоновое аудио и ссылки | управлять поведением приложения |

«Добавить сет» открывается из библиотеки как push-задача. Карточка сета — push, плеер — fullscreen, выбор фото — системный picker, результат сканирования — modal-state.

Вход по номеру не является стартовым шлюзом: `Профиль → аккаунт → номер → SMS-код → Профиль`. Без входа работают каталог, прослушивание, локальная библиотека и все пять системных возможностей. Авторизация нужна только для переноса коллекции и прогресса между устройствами.

## Ключевые маршруты

### Прослушивание

`Главная → Neon Garden → Слушать сет → Слушать в фоне → экран блокировки`

Свернуть плеер возвращает в карточку. Возврат из карточки ведёт на главную — канонический parent для вертикального среза.

### Поиск

`Обзор → поле поиска → результаты → карточка сета → плеер`

Фильтры показывают тип результата, но не создают новый уровень навигации.

### Сохранение по афише

`Моя музыка → Добавить → Камера или Фото → Сет найден → Моя музыка`

Альтернатива без доступа: `Добавить → Ввести код с афиши`.

## Матрица доступов и fallback

| Возможность | Триггер | Разрешение | Успех | Отказ |
|---|---|---|---|---|
| Сканировать афишу | «Сканировать камерой» | Camera | полноэкранный сканер | выбор фото или ручной код |
| Выбрать афишу | «Выбрать из Фото» | Photo Library | системный picker одного снимка | камера или ручной код |
| Слушать в фоне | кнопка в плеере | entitlement без alert | lock screen controls | оставить экран активным |
| Новое для меня | switch в профиле | Notifications | персональные уведомления | новинки остаются на главной |
| Открыть прямую ссылку | «Проверить ссылку» | Associated Domains без alert | карточка deep link | та же страница в Safari |

## Данные и реализация без собственного backend

- Каталог, таймкоды и signed manifest — статический content pack через CDN.
- Аудио — сегментированный поток с локальным кешем и `AVPlayer`.
- Библиотека и позиция воспроизведения — Core Data; синхронизация через private CloudKit.
- Фоновое воспроизведение — `AVAudioSession.playback`, `MPNowPlayingInfoCenter`, `MPRemoteCommandCenter`.
- Камера — `AVFoundation`; распознавание QR и текста — Vision/Core Image на устройстве.
- Выбор фото — `PHPicker`, поэтому приложение получает только выбранный снимок.
- Universal Links — статический AASA на `set.live`.
- Push — APNs через провайдера; регистрация только после согласия.

## Матрица доступов

Каждая строка читается так: пользователь делает жест — система спрашивает — при отказе остаётся рабочий путь.

<!-- @generated:perm-matrix -->
| Ключ | Жест пользователя | Экран | Если отказ | Риск Review |
|---|---|---|---|---|
| `NSCameraUsageDescription` | Сканировать афишу | Афиши | Ручной ввод и выбор из «Фото» остаются доступны | Низкий |
| `NSPhotoLibraryUsageDescription` | Выбрать афишу | Афиши | Камера и ручная настройка остаются | Низкий |
| `UIBackgroundModes: audio` | «Слушать в фоне» в плеере | Neon Garden | Плеер предупредит, что экран должен оставаться активным | **Условный** — AVAudioSession .playback + Now Playing + remote commands |
| `aps-environment` | Свитч «Новое для меня» | Профиль | Новинки видны в главной витрине | **Условный** — Реальная регистрация APNs |
| `com.apple.developer.associated-domains` | «Проверить ссылку» в профиле | Профиль | Та же страница откроется в Safari | Высокий |

## Информационная архитектура

Дерево выведено из разметки экранов, а не нарисовано руками: рукописная схема расходится с прототипом первой же правкой.

<!-- @generated:ia-tree -->
```
Главная (home) — tab (root, start) · открывается: старт
    ├─ Обзор (discover) — tab (root) · открывается: «Радио», «Обзор» …
    │   └─ Результаты (search) — push · открывается: «Поиск», «Диджей, клуб или жанр» …
    ├─ Neon Garden (detail) — push · открывается: «LIVE · MUTABOR», «21:30» …
    │   └─ Neon Garden (player) — fullscreen · открывается: «Neon Garden», «Слушать» … · audio
    │       └─ Экран погас (background) — system · открывается: «Фоновый режим», «Фоновое аудио» (audio)
    ├─ Моя музыка (library) — tab (root) · открывается: «Моя музыка», «Сохранить в мою музыку»
    │   └─ Афиши (studio) — push · открывается: «Добавить сет», «Добавить по афише» … · camera, photo
    │       ├─ Сканировать афишу (capture) — fullscreen · открывается: «Сканировать камерой» (camera)
    │       │   └─ Сет найден (result) — modal · открывается: «Сканировать», «Добавить»
    │       ├─ Фото (pick) — system picker · открывается: «Выбрать из «Фото»» (photo)
    │       └─ Нужен доступ (denied) — state · открывается: «Как работают доступы», «Доступы приложения»
    └─ Профиль (profile) — tab (root) · открывается: «Профиль», «Войти» · push, domains
        ├─ Вход по номеру (phone) — modal · открывается: «В»
        │   └─ Код из SMS (code) — push · открывается: «Получить код»
        │       └─ Неверный код (codefail) — push · открывается: «Код из четырёх цифр»
        └─ Открыто по ссылке (deeplink) — modal · открывается: «Проверить ссылку» (domains)
```
