## Описание

«Сет» сохраняет живое выступление целиком: с площадкой, датой и точным треклистом. Находите эфиры и записи, продолжайте с нужного места, слушайте при погашенном экране и сохраняйте играющий трек одним действием.

Афишу можно отсканировать камерой, выбрать одним снимком через системный picker или ввести код вручную. Камера и медиатека не запрашиваются при запуске.

## App Privacy

Выбранный снимок относится к `User Content → Photos or Videos`, используется только для работы приложения, не связан с личностью и не применяется для tracking. Распознавание выполняется на устройстве. Камера не записывает и не отправляет изображение. ATT не используется.

## Review Notes

Приложение открывается сразу на главной; аккаунт не нужен. Проверка разрешений:

1. «Моя музыка» → «Добавить сет» → камера или «Фото».
2. `Neon Garden` → плеер → «Слушать в фоне».
3. Профиль → «Новое для меня» для notifications.
4. Профиль → «Проверить ссылку» для Universal Link.

Каждый отказ оставляет рабочий fallback. Для камеры и «Фото» доступен ручной код; без push новинки остаются на главной; без фонового режима плеер просит оставить экран активным.
