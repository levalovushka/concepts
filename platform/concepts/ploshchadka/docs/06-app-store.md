# App Store

**Name:** Площадка: смена в ритме
**Subtitle:** Call sheet, кадры и рация
**Category:** Productivity / Utilities
**Age rating:** 13+
**Price:** бесплатно, без покупок

Площадка собирает один съёмочный или событийный день в рабочий контур: call sheet, роли, тайминг, карта зон, обязательные кадры, рация и передача рядом. Откройте смену по коду без аккаунта; критичный план и отметки доступны офлайн.

Ревью: код гостевой смены `314159`. Тестовый аккаунт `+7 700 000-00-31`, пароль `Stage-2026`. До явного жеста разрешения не запрашиваются.

Юридические URL: `ploshchadka.day/privacy`, `ploshchadka.day/support`, `ploshchadka.day/terms`.
