# Караван — референсы и решения

- Apple Human Interface Guidelines, Privacy: запрос появляется после понятного жеста. Решение — ноль запросов на старте.
- Apple Core Location: Always требует продолжаемой фоновой ценности. Решение — таймер, видимая аудитория и автостоп.
- Apple Local Network Privacy: Bonjour discovery вызывает prompt. Решение — триггер «Найти машины рядом» и очередь при отказе.
- Apple Background Tasks: задачи не гарантируют точное время. Решение — интерфейс показывает «ожидает», а не обещает дедлайн.

Из ОК не переносим ленту, публичный профиль, подписки, лайки, бесконечную выдачу и социальный граф. Знакомыми остаются закрытое приглашение, короткая коммуникация и общий альбом — все подчинены одной поездке.
