# Караван — дизайн-система

- Единственный шрифт — Inter, веса 400–800.
- Фон `#F4F3EF`, белые поверхности, тёмный дорожный цвет `#183F47`, жёлтый акцент `#E7B516`.
- Боковые поля — 16 pt, базовый шаг — 4 pt, минимальная интерактивная высота — 44 pt.
- Карточки отделяются фоном и расстоянием; декоративные обводки, тяжёлые тени и капс не используются.
- Активная поездка получает одно главное действие. Машина — позывной экипажа, не социальный аватар.
- Формы используют белые поля без цветных полос. Профиль и аккаунт явно доступны из раздела «Ещё».
