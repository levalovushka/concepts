# Архитектура и сценарии

Источник правды — `concept.json`; переходы подтверждаются реальными `data-go`, `data-ask` и `data-activate` в экранах.

## Домен

`Shelter` содержит `Animal` и `Shift`. Смена связывает `Volunteer` и `Task`; задача принадлежит животному. `Observation` хранит проверяемый факт, автора и время. `Handoff` соединяет две смены и требует подтверждения получателя.

## Восемь сценариев

1. Вход по телефону и паролю без системных запросов.
2. Сегодня → задача → результат → передача.
3. Животное → новое наблюдение → камера или Фото → история.
4. Свободные смены → состав → запись на смену.
5. Передача → устройство рядом → подтверждение получателя.
6. Маршрут по корпусам → животное → задача.
7. Люди → профиль → предложение конкретной задачи.
8. Настройки → оповещения, фон, приватность и приглашения.

## Слои

UI не хранит разрешения. Domain задаёт инварианты: у задачи есть животное, у наблюдения — смена и автор, у передачи — получатель. Services объединяют Auth, Permissions, hosted sync, media, local transfer, background tasks и notifications. Локальный слепок и очередь позволяют закончить действие без сети.
