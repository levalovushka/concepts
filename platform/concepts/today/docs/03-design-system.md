# Сегодня — дизайн-система

Интерфейс использует знакомую мобильную грамматику VK-сервисов: компактная panel header, плотные списки, прямой push/back, пять постоянных tabbar-разделов и системно понятный синий action color. Самостоятельность бренда задают словесный знак «Сегодня.», план-first IA и отсутствие контентной витрины.

## Токены и правила

- Action color: `#2688EB`; основной текст `#17181A`; вторичный `#74777C`; фон контролов `#F2F3F5`.
- Manrope используется только в реальных начертаниях: `500` для основного текста, `600` для кнопок, chips и названий строк, `700/800` для заголовков. Дробных синтетических весов нет. Размеры: 32 px для главного вопроса, 28 px для root-title, 17–19 px для section/header, 11–14 px для служебного текста.
- Lucide SVG: 22 px в headers/rows, 23 px в tabbar; stroke `2`, единые round caps/joins.
- Touch targets: не меньше 44 pt. Primary button — 52 pt. Root tabbar — 82 pt вместе с нижней safe area.
- Радиус функциональный: 12 px controls, 14–16 px grouped surfaces, 18 px photo cover. Теней почти нет; разделение строится ритмом, фоном и редкими hairline.
- Карточки применяются только для самостоятельных объектов: совпадение, место, plan snapshot. Обычные настройки и участники остаются списками без внешней рамки.
- Люди представлены буквенными avatar-placeholders с устойчивым цветом на человека. Иллюстративные лица не используются; фотографии остаются только у событий и необязательной обложки плана.
- Filter chips имеют общую высоту 38 px, единый радиус 12 px и трёхколоночную сетку; ширина учитывает длину русских подписей без overflow.

Приватность не прячется в настройках: lock-label присутствует на совпадениях, в редакторе и в деталях плана.
