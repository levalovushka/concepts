## Описание

Структура «фича — что она даёт», без перечня возможностей:

1. Что это и для кого — видеосервис о ремонте своей машины, где разбор ищут звуком.
2. **ЗАПИСЬ ЗВУКА** — десять секунд там, где слышно; записи остаются у вас, до ремонта и после.
3. **СРАВНЕНИЕ С ЭТАЛОНОМ** — две дорожки рядом и переключатель. Решает ухо; приложение ничего не распознаёт и диагноз не ставит.
4. **РАЗБОРЫ ЦЕЛИКОМ** — порядок операций, инструмент, артикулы. Скачиваются в гараж, где нет сети.
5. **ГОЛОС В ФОНЕ** — звук продолжает играть при заблокированном экране, ±15 секунд с локскрина.
6. **ПРИЁМЫ НА МИНУТУ** — короткие вертикальные видео.

Фраза «приложение ничего не распознаёт и диагноз не ставит» стоит в описании намеренно: она совпадает с тем, что делает сборка, и снимает у ревьюера вопрос, ради которого обычно и тянут за микрофон.

## Демо-доступ для ревьюера

Первый экран — вход по номеру, без тестового номера дальше не пройти.

- Номер: **+7 900 000-00-00**
- Код: **0000**
- SMS не отправляется, тестовый номер принимает код 0000.

## Review Notes

Каждый доступ спрашивается за конкретным жестом, ни одного промпта на первом запуске.

| Доступ | Как дойти (2–3 тапа) |
|---|---|
| ATT (трекинг) | После входа — экран «Смотреть можно бесплатно» → «Продолжить бесплатно» |
| Микрофон | Вкладка «Звук» → «Записать звук». Подойдёт любой шум: сравнение с эталоном откроется в любом случае |
| Камера + микрофон | Вкладка «Снять» → «Снять ремонт» |
| Медиатека (чтение) | Вкладка «Снять» → «Выбрать из медиатеки» |
| Медиатека (запись) | Главная → любой разбор → «Вырезать в „Фото“» |
| Локальная сеть | Главная → любой разбор → иконка телевизора в плеере |
| Геопозиция | Главная → разбор → «Где взять деталь». Второй вход — карточка симптома → «Где взять втулки рядом» |
| Фоновое аудио | Главная → разбор → «Слушать». Экран можно заблокировать: звук продолжится, на локскрине — Now Playing и ±15 секунд |
| Уведомления | Профиль → «Подписки и уведомления» → свитч «Новые разборы» |

При отказе в любом из них приложение остаётся рабочим: на экране, куда приводит отказ, показывается, что именно перестало работать и чем это заменено.

## Ключ, который не заявлен

`com.apple.developer.associated-domains` из целевого набора **не заявлен**. Диплинков в концептах не проектируем и не рисуем, а заявлять ключ, за которым нет достижимой фичи в этой же сборке, нельзя — это прямое нарушение правила «фича, а не причина». Набор здесь недобран сознательно: 9 ключей из 10. Решение по десятому принимает человек.

## Скриншоты и превью

Порядок кадров = порядок ценности:

1. **Звук** — «Стук нельзя показать пальцем» и кнопка записи.
2. **Сравнение** — две дорожки и переключатель «мой звук / эталон».
3. **Карточка симптома** — эталон, частота, что проверить первым.
4. **Разбор** — шаги с таймкодами и артикулы.
5. **Экран погас** — Now Playing поверх локскрина.
6. **Скачано** — офлайн-библиотека в гараж без сети.
