## Что проверено отдельно

- **Статус-бар читается на всех экранах.** Тёмные поверхности (`clips`, `camera`, `record`, `background`, `watch`, `cast`) объявлены `light: false`, светлые — `light: true`.
- **Плейсхолдер не стоит героем композиции.** `.ph` занимает место кадра видео (лента, плеер, миниатюры строк, сетка медиатеки) — там, где в жизни лежит кадр. Единственная крупная серая плоскость — кадр плеера на `watch`, и это ровно то место, где у видеосервиса видео.
- **Списки неоднородны по состоянию.** «Скачано» несёт разом: скачано 412 МБ · качается 17 % · ждёт Wi-Fi 1,1 ГБ · автор удалил, остался офлайн. «Мои записи» — совпало · тихо · не сравнивалось · не совпало · запись обрезана. «Черновики» — не смонтирован · готов · звук тише, чем нужно · экспортируется 41 %.
- **Числа неровные.** 187 400 км, 84,2 тыс., 7 812 просмотров, 1 560 ₽, 2,8 удара/с, 214 Гц, 06:41.
- **УТП читается с первого экрана вкладки «Звук»** за пять секунд: «Стук нельзя показать пальцем» + кнопка «Записать звук» + список своих записей с отметками «совпало / тихо / не совпало».

## Чем проверено машинно

- `npm run test -- stuk` — 45/45 зелёных.
- `npm run lint -- stuk` — расхождений нет.
- `npm run audit -- stuk` — чисто (рамка агента, кегль ниже 11 pt, усечение многоточием, выход за края, хит-таргеты, подвал поверх списка).
