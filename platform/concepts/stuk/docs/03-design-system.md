# Стук — дизайн-система

Системный iOS-хром живёт в `kernel/base.css` и в сторибуке `components.html`. Здесь только то, что добавляет концепт. Все имена с префиксом `sk-`, чтобы не столкнуться с ядром: класс, объявленный с нуля и в ядре, и в концепте, молча ломает страницу.

## Цвет

| Токен | Значение | Где работает |
|---|---|---|
| `--sk-ink` | `#141210` | Текст, марка, активный чип, кнопка «Похоже» |
| `--sk-accent` | `#0077ff` | Акцент: таймкоды шагов, дорожка своей записи, «Слушать», кнопка записи |
| `--sk-steel` | `#3a5a78` | Второй смысловой цвет — **только** эталонная дорожка и её миниатюра |
| `--sk-muted` / `--sk-faint` | `#6f6a64` / `#a09a92` | Подписи и второстепенные числа |
| `--sk-soft` / `--sk-warm` | `#f5f2ec` / `#eaf3ff` | Нейтральные и акцентные подложки: карточки, чипы, fallback |
| `--sk-line` | `#e6e2dc` | Разделители списков |
| `--sk-ok` | `#2c7a4b` | Отметка пройденного шага и метка «помогло» |

Акцент один — янтарь приборной панели. Стальной синий не конкурирует с ним за главность: он закреплён за чужой (эталонной) записью, и именно поэтому на экране сравнения сразу видно, где своё, а где каталожное. У соседних концептов набора (`radius`, `liga`) акцент красный — здесь он намеренно другой.

Тёмный вариант акцента `#ffa63d` подставляется ядром в тёмной теме (`brand.accentDark`).

## Типографика

- **Manrope** — интерфейс. 800 для заголовков, 700 для строк списка, 400–600 для подписей.
- **IBM Plex Mono** — всё, что является данными: таймкоды (`00:00`, `06:41`), частоты (`220 Гц`), удары в секунду, пробег, размеры файлов, номер телефона, артикулы.

Правило простое: если число можно сравнить с соседним — оно моноширинное.

## Компоненты концепта

| Класс | Что это |
|---|---|
| `.sk-wave` / `.sk-wave.ref` / `.sk-wave.live` | Дорожка звука: своя, эталонная, идущая запись. Картинка — из `media.mjs` |
| `.sk-take-wave` (`.quiet` / `.hum` / `.tick`) | Миниатюра дорожки в списке: четыре характера звука |
| `.sk-ab` | Переключатель источника «мой звук / эталон» |
| `.sk-cmp-head`, `.sk-facts` / `.sk-fact` | Заголовок дорожки с числами и плитки сравнения |
| `.sk-verdict` | Ответ человека: «Похоже» / «Не то» |
| `.sk-sym`, `.sk-sym-hz` | Строка каталога симптомов с частотой справа |
| `.sk-step`, `.sk-time` | Шаг разбора с таймкодом |
| `.sk-part`, `.sk-part-code` | Деталь с артикулом и ценой |
| `.sk-shop`, `.sk-map`, `.sk-pin` | Точки с деталью и карта под ними |
| `.sk-rec-*` | Экран записи: счётчик, подсказки, кнопка |
| `.sk-backdrop`, `.sk-scrim` | Затемнённый разбор под шторкой выбора телевизора |
| `.sk-dl*`, `.sk-tag` | Офлайн-библиотека и состояния строк |

Индикаторы скачивания (`.dl`, `.dl-bar`), плейсхолдер (`.ph`), лист (`.sheet`), камера (`.cam`), локскрин (`.lock-bg`), таб-бар и навбар — из ядра, своих аналогов нет.

## Медиа

Фотографий и иллюстраций в концепте нет: везде, где по макету кадр или обложка, стоит `.ph`. Кодом (`media.mjs`, детерминированный seed вместо `Math.random`) рисуются только данные:

- `wave-mine.svg`, `wave-ref.svg`, `wave-live.svg` — дорожки звука;
- `wave-thumb-*.svg` — те же дорожки крупным штрихом для списка: на 82 пикселях ширины полосы полноразмерной дорожки сливаются в шум;
- `map.svg` — схема кварталов под списком точек с деталью.

Дорожка — не украшение: без неё сравнение превращается в две кнопки «играть», и фича перестаёт быть понятной с экрана.

## Три ловушки, которых здесь нет

1. Ни один класс концепта не повторяет имя из ядра — проверяет линтер.
2. Там, где класс несёт `background-image` (`.sk-wave`, `.sk-take-wave`, `.sk-map`), используется `background-color`, а не шорткат `background`.
3. Отступы секций заданы `margin-bottom`, а не шорткатом `margin`, чтобы не гасить утилиты `.mt*` из ядра.
