# Дизайн-система

Тёмный нейтральный фон `#0b0b0e`, один фиолетовый акцент `#6757f5`, Manrope для UI и IBM Plex Mono для таймкодов. Контент первичен: минимум бордеров, поверхности разделяются расстоянием и тоном. Lucide 22 px со stroke 2.

Медиа-система состоит из самостоятельных концертных сцен: группа «Маяк» с гитарой, клавишами и барабанами; электронный дуэт; крупный план Ады Мороз; фестивальный общий план; портрет фронтмена; гитарный момент; зрительская камера и архитектура площадки. Hero, карточки, плеер, момент и канал используют разные планы одного визуального мира.
