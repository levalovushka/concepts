# Партия — дизайн-система

Язык взят из Base Kit (набор VK-типа: `vk-style-visual-guide.en.md` + `design-tokens.json`) и отстроен по механизму, который в самом наборе назван самым безопасным для замены — §8: темизируемый акцент, гарнитура, радиус контрола. Системный iOS-хром (статус-бар, permission-алерт, снекбар, home indicator, таб-бар, сканер) берётся из ядра и в концепте не переопределяется.

## Токены концепта

| Токен | Значение | Где работает |
|---|---|---|
| `--accent` / `--accent-fill` | `#9B2C4A` | Заливка главной кнопки, акцентный текст, активная вкладка, номер текущего номера программы |
| `--accentDark` | `#F2A0B4` | Тёмная тема страницы документа |
| `--pa-rose` | `#F2A0B4` | Тот же тон на тёмных поверхностях: плеер и локскрин. Бордо на чёрном не читается |
| `--pa-sub` | `#6D7885` | Второстепенный текст, 4.6:1 на белом |
| `--pa-mute` | `#79818C` | Третичный: мета-строки списка. Исходный `#99A2AD` набора давал 2.4:1, а через третичный тон здесь идёт почти вся мета |
| `--pa-line` | `#D7D8D9` | `separator.primary` первоисточника |
| `--pa-warn` / `--pa-warn-bg` | `#8A5300` / `rgba(248,160,28,.18)` | «Шатко», «переснять». Сам `#F8A01C` текстом давал 2.1:1, поэтому носитель разделён: заливка одна, текст другой |
| `--pa-ink-dark` | `#17090D` | Подложка под белой кнопкой воспроизведения |
| `--face` | `Inter` 400–700 | Вся типографика интерфейса |
| `--mono` | `IBM Plex Mono` 400–500 | Числа предметной области: такты, буквы, таймкоды, даты, минуты |
| `--r-btn` (в `.screen`) | `10px` | Радиус контрола первоисточника (§5) вместо капсулы ядра |

Моноширинный здесь не украшение: в этой предметной области чисел больше, чем слов — «т. 41–74», «с буквы В», «25.II», «2:14», «96 тактов». Разделение гарнитур делает данные читаемыми как таблицу, а не как прозу.

## Отстройка от первоисточника

| Что | В первоисточнике | У нас | Почему |
|---|---|---|---|
| Акцент | `#2688EB` | `#9B2C4A` | Другое семейство тона. Механизм замены — §8: темизируемый акцент отделён от базового именно для этого |
| Гарнитура | SF Pro Text / Roboto | Inter | §8 называет Inter одним из двух примеров замены |
| Радиус контрола | 10pt iOS | 10pt | **Взято как есть.** Второй концепт на этом же языке ушёл в 8pt; отстраиваться дважды одним и тем же приёмом смысла нет |
| Фон страницы | `background.page` = `background.content` = белый | белый | Тоже как есть — по той же причине |
| Разделители | hairline `separator.primary` между ячейками | hairline во всю ширину, отступ слева 16 | Взято как есть: у соседнего концепта разделителей нет вовсе, и это была его отстройка, а не общая |
| Плотность ячейки | Headline 16/20 | 16/20 внутри `.pa-list` | Ячейка ядра — iOS 17/22. Внутри списков концепта возвращена плотность первоисточника |
| Заголовок раздела | Title 3 17/22 по центру | Large title 34/41 слева (из ядра) | Корни вкладок — системный iOS. Здесь первоисточник проигрывает системе: заголовок вкладки в iOS большой |
| Цветные плитки меню | двухтоновый градиент, 15 акцентных цветов | нет | Второго акцента в концепте нет вовсе. Голоса различаются **не цветом**, а тем, что свой голос акцентный, а три остальных серые — это и есть продуктовая мысль |
| Иконки | SF Symbols | спрайт Lucide из ядра | Итоговый файл самодостаточен, в системный шрифт он ходить не может |

## Свои компоненты

Всё с префиксом `pa-`; в `base.css` такого префикса нет, поэтому коллизия имён (первая из трёх ловушек CSS) исключена по построению.

| Класс | Что это |
|---|---|
| `.pa-ruler` / `.pa-seg` | Линейка тактов: 96 тактов, разбитых репетиционными буквами. Ширина сегмента пропорциональна числу тактов в букве (24 / 16 / 34 / 22), внутри активного — линия проигранного. Это данные экрана, а не визуал |
| `.pa-key` / `.pa-let` | Носители навигации по произведению: голос (С А Т Б, сквиркл) отвечает «какая строчка», репетиционная буква (круг) — «откуда» |
| `.pa-flag` | Чип состояния: «уверенно», «шатко», «купюра т. 33–40», «переснять», «страниц нет» |
| `.pa-num` / `.pa-date` | Моноширинные ведущие: номер в программе, дата выпуска дополнения |
| `.pa-notes` / `.pa-note` | Пометки с розданной ксерокопии: слева такт или буква, справа то, что написано карандашом |
| `.pa-np` / `.pa-notif` | Now Playing и уведомление на локскрине |
| `.pa-frame` / `.pa-cam-read` | Рамка системного сканера страниц и строка распознанных тактов |
| `.pa-weeks` / `.pa-week` | Столбцы минут по неделям в журнале |
| `.pa-page-thumb` | Миниатюра страницы: портрет 46×61 вместо пейзажной миниатюры ядра — страница нот вертикальная |
| `.pa-quiet` | Блок fallback при отказе доступа |

## Медиа

Своих ассетов у концепта нет: `media.mjs` создаёт `assets/media` и оставляет каталог пустым. Всё, что было бы фотографией — страница нот, снимок с репетиции, обложка номера в Now Playing, — плейсхолдер `.ph` (`.ph.on-dark` на тёмном).

Данные, нарисованные кодом, — линейка тактов, столбцы недель, рамка сканера — это содержимое экрана, без которого фича непонятна, а не визуал.

Отдельно проверено правило «`.ph` не герой композиции»: первая версия экрана страниц показывала сетку 2×2 из крупных плейсхолдеров на пол-экрана. Заменено на список строк с портретными миниатюрами, где вокруг миниатюры — данные страницы: диапазон тактов, что на ней карандашом, чего не хватает.

## Три ловушки CSS

1. **Коллизия имён.** Все свои классы с префиксом `pa-`; проверяется `lint-concept.mjs --kernel`.
2. **Шорткат `background`.** В `styles.css` не используется ни разу — только `background-color`.
3. **Шорткат `margin`.** Не используется — только `margin-top` / `margin-bottom`, иначе гасятся утилиты `.mt*` ядра.
