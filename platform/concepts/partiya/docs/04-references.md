# Партия — референсы паттернов

Первоисточник визуального языка один и назван прямо: набор VK-типа — `Base Kit/vk-style-visual-guide.en.md` и `design-tokens.json`. Значения в нём вытащены из Figma-переменных VKUI программно, а не сняты на глаз, поэтому опираться на них можно как на спецификацию. Второй источник — системные паттерны iOS (HIG, `kernel/ios-chrome.md`): permission-алерт, снекбар, статус-бар, локскрин, сканер документов, Now Playing и таб-бар берутся оттуда и не перерисовываются.

## Что не удалось прогнать и почему

Честно, чтобы не выглядело недоработкой:

- **scrn.gallery, галерея экранов ВК Музыки** (`/app/vk-music`) — **прогон не выполнен**. Домен заблокирован политикой в браузерной панели, прокликать переходы нельзя. Через WebFetch страница читается, но из 67 экранов публичны 10, а ссылок на сами изображения в разметке нет — единственный найденный файл это логотип сайта. То есть экраны ВК Музыки в работе **не использовались**, и совпадений с ними ждать не следует.
- **Mobbin** — коннектор подключился, прогон выполнен, но **ВК Музыки в базе нет**: на запрос про музыкальный плеер вернулись Apple Music, Deezer, Epidemic Sound, Spotify Kids, WeChat. Для проверки общей раскладки плеера этого достаточно, для сверки с целевым приложением — нет.

Отсюда следствие для оценки концепта: визуальное сходство с ВК Музыкой опирается на токены и блюпринты Base Kit, а не на разбор её экранов.

## На какие паттерны опирается прототип

| Паттерн | Где применён | Откуда взят |
|---|---|---|
| **Cell / Rich Cell** — ведущая иконка или миниатюра, заголовок с подписью, значение или шеврон справа | все списочные экраны (`.pa-list` + `.row` ядра) | Base Kit §6, Cell / Rich Cell |
| **Hairline `separator.primary` во всю ширину** между ячейками, перед первой строкой разделителя нет | те же списки | Base Kit §6 Separator, §9 Messenger, пункт 4 |
| **Group Header** — заголовок секции над списком | `.pa-sec` на всех экранах | Base Kit §6, Group Header/Footer |
| **Search-пилюля** с лупой слева на `background.secondary` | `notes` (`.searchfield` ядра) | Base Kit §6 Search + §9 Messenger, пункт 2 |
| **Content Badge** — цветной текст-чип статуса | `.pa-flag`: «шатко», «купюра т. 33–40», «переснять» | Base Kit §6, Badge / Content Badge |
| **Badge / Counter** — красная точка у строки с новым | строка «Дополнения» на `program` (`.row-dot` ядра) | Base Kit §6 |
| **Плотность 16/20** в ячейке вместо системных 17/22 | `.pa-list .t-headline` / `.t-body` | Base Kit §3, Headline 1 / Text |
| **Радиус контрола 10, карточки 16** | кнопки, `.pa-quiet`, `.pa-np` | Base Kit §5 |
| **Стат-ряд колонками с разделителями сверху и снизу** | `journal` (`.pa-stats`) | Base Kit §9, Profile, пункт 4 |
| **Плоские блоки без теней**, разделённые воздухом | вся светлая часть | Base Kit §1 |
| **Два уровня тёмного** на иммерсивной поверхности | `player`: страница темнее блоков `rgba(255,255,255,.09)` | Base Kit §11: `background.page` темнее `background.content` |
| **Permission-алерт и снекбар с путём в Настройки** | все экраны с доступами (из ядра) | iOS HIG, `kernel/ios-chrome.md` |
| **Системный сканер документов** — затемнение вне кадра, рамка найденного разворота, счётчик страниц, «Сохранить N страниц» | `camera` (`.pa-frame`, `.cam-*` ядра) | `VNDocumentCameraViewController` |
| **Now Playing на локскрине** — обложка, две строки, полоса, три контрола | `background` (`.pa-np`) | iOS, `MPNowPlayingInfoCenter` |
| **Уведомление на локскрине** — имя приложения капсом, заголовок, текст | `notif` (`.pa-notif`) | iOS |
| **Ячейки OTP** — четыре квадрата, заполненные и активный | `code` (`.otp-cell` из ядра) | iOS, общий для всех концептов вход по номеру |
| **Линейка тактов по репетиционным буквам** | `player` (`.pa-ruler`) | **не из Base Kit и не из мобильных продуктов**: это раскладка репетиционной цифры в партитуре. Прямого референса не нашлось, потому что задачи «показать 96 тактов четырьмя буквами» в аудиоплеерах не бывает |

### Приёмы, взятые сознательно как есть

Второй концепт репозитория на этом же визуальном языке отстроился от первоисточника серой страницей под белыми карточками, полным отказом от разделителей и радиусом 8. Здесь всё три пункта взяты **как в наборе** — белая страница, hairline, радиус 10. Причина простая: отстройка одним и тем же приёмом дважды перестаёт быть отстройкой, а различать два концепта должны акцент, гарнитура и предметные компоненты, а не повторный трюк с фоном.

## Что осознанно не копируем

| Что | В первоисточнике | У нас | Почему |
|---|---|---|---|
| **Вордмарк и брендовая капсула в верхней строке** | пилюля со знаком в строке статус-бара | нет ни на одном экране | В первоисточнике она живёт в строке статус-бара, а его рисует ядро. Отдельный ряд под статус-баром изображал бы элемент интерфейса, которого в сборке не существует |
| **Ряд сторис** | круги 52–56 с акцентным кольцом | нет | Ни сторис, ни чужого контента в концепте нет |
| **Карточка поста и ряд действий** | лайк / комментарий / репост | нет | UGC вырезан на фазе 4 |
| **Пятнадцать акцентных цветов** | палитра для статусов и тегов | три состояния: акцент, серый, оранжевый-предупреждение | Второй акцент запрещён правилом платформы |
| **Цветные плитки меню** | двухтоновый градиент | нет | Раздела «Меню» нет; вкладок три |
| **Swipe actions** | на ячейках | нет | Прототип статичный, жест на PNG не проверяется — значит не заявляется |
| **Elevation 1/2/3** | система теней | нет теней в контенте | Тени только там, где они системные: `.pa-np` и `.pa-notif` на локскрине держатся blur’ом, а не высотой |
| **Grid avatar и инициалы** | до четырёх фото, инициалы как fallback | нет | Аватаров нет вовсе: людей в концепте не показываем, показываем состав партии числом |
| **Тёмная тема интерфейса** | полный второй набор токенов (§11) | нет | Страница залочена в светлую. Значения §11 использованы точечно — на двух тёмных поверхностях (`player`, локскрины), а не как вторая тема |

## Чего избегаем

- **Капсульные кнопки Apple.** В ядре есть `--r-btn: 9999px`; внутри `.screen` он переопределён на 10px — значение первоисточника.
- **Второй акцентный цвет.** Голоса различаются не цветом, а тем, что свой акцентный, остальные серые.
- **Свои SVG-пути.** Все глифы — из спрайта Lucide; нет иконки — она заводится в `gen-icons.mjs` и ядре.
- **Иконка `clock` в таб-баре.** Активная вкладка в ядре заливается (`fill: currentColor`), и `clock` превращался в глухой круг. Журнал получил `book-open`, программа — `layout-grid`.
- **Диплинки** — Universal Links, `associated-domains`, приём чужих ссылок. Правило платформы: не проектируем, ключ не заявляем.
- **Иллюстрации и стоковые фото.** Медиа — только плейсхолдер `.ph`.

## Что проверить, когда появится доступ к галереям

| Что искать | Зачем |
|---|---|
| ВК Музыка: плеер, очередь, экран альбома | Главное неисполненное: сверить раскладку плеера и Now Playing с целевым приложением |
| Приложения для хоров и оркестров (Choir Genius, MuseScore, forScore, Newzik) | `piece` и `player`: как показывают партию одного голоса и репетиционные цифры |
| forScore, Newzik: библиотека партитур | `notes`: раскладка «страницы по произведениям» и что делают с криво снятым разворотом |
| Document scanner в Notes, Dropbox, Scanner Pro | `camera`: подпись счётчика страниц и кнопка сохранения многостраничного скана |
| Photo library auto-selection («этот день», «снимки рядом») | `import`: как объясняют, что приложение само обошло библиотеку, и как дают отменить |
| Плееры с A–B петлёй (Amazing Slow Downer, Anytune) | `player`: как показывают границы повторяемого фрагмента |
| Экраны «что нового в паке» в офлайн-приложениях | `releases`: раскладка истории выпусков со состоянием загрузки |
