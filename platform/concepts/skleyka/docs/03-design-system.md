# Склейка — design system

## Характер

Зрелый инструментальный consumer UI: светлые поверхности управления и тёмные поверхности видео. Акцент #5B5BD6 обозначает выбранное действие, playhead и локальный progress, но не используется как декор.

Базовый горизонтальный отступ — 16–18 pt. Главные заголовки 25–30 pt, навигационные 16 pt, минимальный текст 11 pt. Карточки появляются только там, где объединяют состояние: активный проект, запрос материалов, preview и выбранное качество.

Один согласованный atlas содержит шесть кадров одного события. Кадры используются как данные: источник, длительность, порядок и состояние обработки видны поверх preview. Пустых placeholder, декоративных SVG и случайных иллюстраций нет.

Root-разделы «Проекты», «Архив», «Настройки» имеют один tab bar. Внутренние и системные экраны идут по отдельному стеку. Только Lucide из kernel sprite; hit target не меньше 44 pt.
