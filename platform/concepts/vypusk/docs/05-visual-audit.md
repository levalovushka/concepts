# Выпуск — визуальный аудит

Проверяются 31 экран: обрезка, пустота, провалы подложки, кроп, контраст, ритм, иерархия, iOS-хром и повтор медиа. Контактный лист используется только для целостности; каждый PNG открывается отдельно в полном размере.

Особое внимание: длинные названия школ и вузов; двухстрочные статусы в составе; непереполненная строка ввода; белый статус-бар на светлых экранах; тёмная сцена под звонком и Cast. Дополнительный запрет — никаких сгенерированных аватаров, обложек или иллюстраций: только `.ph` / `.ph.on-dark`, круг 44×44 для человека и 74×56 для превью. Фактические проходы записаны в `07-quality-evidence.md` после повторной съёмки.
