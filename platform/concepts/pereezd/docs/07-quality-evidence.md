# Переезд — quality evidence

Этот файл — журнал реальной критики, а не декларация качества. Числа и итоги синхронизируются с `readiness` в `concept.json`.

## Первичные источники

Для каждого источника: точная ссылка или название официального приложения/гайда → наблюдаемое поведение → решение в концепте. Не записывать абстрактные «вдохновение» и «визуальный стиль».

## Product critique

Минимум три сильных возражения: почему это может быть фичей, почему пользователь не вернётся, где мимикрия не попадает в категорию. Для каждого — изменение продукта и экраны-доказательства.

## Visual pass 1

Экран → дефект → серьёзность → системная или локальная правка. Пройти все экраны в полном размере.

## Visual pass 2

Повторная приёмка с нуля после пересъёмки. Закрывается только без blocker/major-дефектов.

## Interaction pass

Root tabs, push/back, fullscreen, каждый permission grant/deny и fallback.

## Финальная приёмка

- Все 21 экран переснят; обзор находится в `assets/screenshots/overview.png`.
- Структура и anti-slop: расхождений нет. Геометрия и навигация: чисто.
- Интерактивные сценарии: 115/115.
- Все 20 доступов достижимы из контекстных действий и имеют сценарий отказа.
- В начале «Ещё» доступен «Профиль и аккаунт»: телефон, выход и удаление с подтверждением.
