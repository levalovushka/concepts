## Матрица системных интеграций

| Интеграция | Видимый путь | Результат | Отказ |
|---|---|---|---|
| Camera | Профиль → Визуал сессии → Считать свет камерой | системный prompt → capture | возврат в studio, fallback виден |
| Photo | Профиль → Визуал сессии → Выбрать цвет из фото | системный prompt → PHPicker | возврат в studio, fallback виден |
| Push | Профиль → Напоминания | системный prompt → profile | profile, fallback виден |
| Background audio | Player или Профиль → Фоновое аудио | capability → lockscreen | экран остаётся активным при недоступности |
| Universal Links | Профиль → Проверить ссылку | capability → deeplink | та же ссылка открывается в Safari |

Grant‑ветки пяти интеграций и deny‑ветки трёх реальных permission prompts проверены автоматизированными кликами в Chromium.
