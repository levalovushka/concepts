# Визуальный аудит

Проверены все 20 экранов на 376×812 после перехода на тёмную оболочку `.vkd` (мимикрия ВК Музыки).

- вход, пароль, регистрация, аккаунт и удаление — тёмные, на тех же токенах, что и продукт;
- таб-бар и мини-плеер — одна нижняя панель, стоят на нижней границе, контент заканчивается выше;
- акцент только синий ВК; мятный `#75E0C1`, зелёный аватар и цифры в кругах убраны;
- шкала кегля VKUI iOS: 34 · 24 · 20 · 17 · 16 · 14 · 13 · 11, строки 16/14, секции 24/600;
- поле 16, строка 72 с обложкой 56, ячейка 48, радиусы 8/10/12;
- у каждой кнопки касание не меньше 44 pt, включая чипсы (пилюля 36, зона 44);
- состояния скачивания в «Любимом» разные у соседних строк: скачано, 62 %, 18 МБ;
- у каждой строки со стрелкой есть переход; текст не усекается.

`test-flows` 59/59, `audit` чисто, `audit:grid` — все строки на одном столбце.

## Матрица системных интеграций

| Интеграция | Видимый путь | Результат | Отказ |
|---|---|---|---|
| Camera | Карточка сессии → Визуал сессии → «Считать свет камерой» | системный prompt → capture | studio, fallback виден |
| Photo | Визуал сессии → «Взять цвет из фото» | системный prompt → PHPicker | studio, fallback виден |
| Push | Главная → «Влад ›» → «Напоминания» | системный prompt → profile | profile, fallback виден |
| Background audio | Плеер → «Слушать в фоне» | capability → локскрин | плеер предупреждает, что экран должен оставаться активным |
| Universal Links | Профиль → «Проверить ссылку» | capability → deeplink | та же ссылка открывается в Safari |
