# «Репетиция»: продуктовый вижен

Локальный B2C-тренер помогает подготовить выступление по временным блокам, проверить кадр и повторить слабый момент. Вход выполняет SDK провайдера; ленты, каталога и облачного анализа нет.

## Основной цикл

Номер → SMS-код → сегодня → настройка плана → проверка кадра или таймер → разбор по блокам → повтор момента.

## Критерий без бэкенда

После входа планы и метки работают в авиарежиме. SDK входа и APNs используют готовую инфраструктуру; собственного API нет.
