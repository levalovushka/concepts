# Репетиция — референсы паттернов

## На какие паттерны опирается прототип

| Референс | Что берём |
|---|---|
| iOS Camera | полноэкранную проверку композиции |
| Voice Memos | крупное время и простой цикл управления |
| Fitness | метрики как второй слой после результата |
| Keynote Presenter Display | план выступления по временным блокам |
| Now Playing | управление локальным повтором на блокировке |

## Что осознанно не копируем

- видеоредактор с timeline монтажа;
- dashboard с десятками оценок речи;
- социальный профиль и публичные записи;
- курс с каталогом уроков;
- экран видеозвонка с тренером.

## Приёмы из Base Kit, которые у нас не применимы

Tab bar, лента одинаковых карточек и профиль с контентом создают впечатление медиасервиса. «Репетиции» нужен один текущий цикл и контекстные переходы к истории и настройкам.

## Чего избегаем

- псевдонаучной оценки эмоций или уверенности;
- красного цвета как единственного объяснения проблемы;
- запроса камеры до настройки цели;
- обещания облачного AI-анализа;
- скрытого сохранения импортированного видео.

## Что проверить по Mobbin, когда появится доступ

Экран завершения тренировки, детализацию одного провала на временной шкале, поведение импорта одного видео и объяснение локального хранения. Референс нужен для паттерна, не для копирования визуального стиля.

## Источники визуального языка

Тёмные инструментальные приложения Apple, Voice Memos, presenter mode и спортивные summary-экраны. Общий принцип — один текущий объект и понятное следующее действие.
