# Архитектура

## Модули

- `RunPlan` и `RunSession` в SwiftData.
- `FrameGuide` на AVFoundation и Vision, без записи звука.
- `TimelineEngine` сравнивает фактические метки с планом.
- `LocalPlayback` играет локальную дорожку и подсказки.
- `PhoneAuthService` использует SDK провайдера; токен хранится в Keychain.
- `PermissionsService` содержит четыре системные возможности и не запрашивает их на входе.

## Внешняя инфраструктура

SDK входа нужен для номера и SMS-кода, APNs и push-SDK — только для напоминания. Ни одна из этих систем не хранит планы или видео.
