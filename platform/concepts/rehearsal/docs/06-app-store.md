# Карточка App Store

**Name:** Репетиция: прогон на видео
**Subtitle:** Запись, разбор и уроки
**Category:** Photo & Video / Education
**Price:** бесплатно, с рекламой

Для review: номер +7 900 123-45-67 и пароль из `appStore.reviewAccount`, либо «Продолжить без аккаунта». На экранах входа нет запросов доступов.

Маршрут ревьюера:

1. Главная → «Начать прогон» → «Проверить кадр и звук» спрашивает камеру и микрофон; отказ оставляет прогон по таймеру.
2. Настройка → «Площадка» спрашивает геопозицию; отказ оставляет поиск по названию.
3. Разбор → AirPlay спрашивает локальную сеть; отказ оставляет разбор на iPhone.
4. Разбор → момент → «Слушать в фоне» включает фоновое аудио и Now Playing; кнопка сохранения спрашивает добавление в «Фото».
5. Профиль → «Добавить прогон из Фото» спрашивает доступ к «Фото».
6. Подписки → «Новые выпуски» спрашивает уведомления.
7. Главная → рекламная карточка или Настройки → «Реклама» → «Показывать по интересам» показывает ATT.

Прогоны, метки и видео не отправляются разработчику. IDFA уходит рекламному SDK только после согласия.
