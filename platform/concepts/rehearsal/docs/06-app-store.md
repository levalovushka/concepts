# Карточка App Store

**Name:** Репетиция: тренер речи
**Subtitle:** Найдите слабое место
**Category:** Productivity / Education
**Price:** бесплатно, без встроенных покупок

Для review используется номер +7 900 000-00-00 и код 0000. На экранах входа нет запросов доступов. Доступы появляются после «Проверить кадр», «Импортировать видео» и включения напоминания.

Номер телефона связан с учётной записью у SDK-провайдера. Планы, метки и видео не отправляются разработчику. APNs token обрабатывает провайдер только после явного включения напоминания.
