# Репетиция — дизайн-система (концепт)

## Направление

Тёмная инструментальная поверхность снижает визуальный шум во время прогона. Коралловый акцент отмечает текущее действие и проблемный фрагмент, но не превращает разбор в тревожную панель ошибок.

## Токены

### Цвет

- фон: `#111216`;
- поверхность: `#1b1d22`;
- вторичная поверхность: `#24262d`;
- акцент: `#ff6b5e`;
- основной текст: `#f7f7f8`;
- вторичный текст: `#8d8f98`.

### Типографика

Интерфейс использует Manrope; таймеры, длительности и метки — моноширинный `--mono` с tabular numbers. Заголовки крупные только на корне и в разборе.

### Радиусы, отступы и safe areas

Основные карточки — 15–17 px, круглые media controls — 50–76 px. Горизонтальный ритм — 18 px. Кастомные шапки используют `--safe-top`, нижние действия — `--safe-bottom`; цели нажатия не меньше 44 pt.

## Требования HIG, которые прототип обязан соблюдать

- permission появляется после конкретного действия;
- камера и PHPicker остаются системными поверхностями;
- playback публикует Now Playing и remote-команды;
- цвет не является единственным носителем статуса;
- reduce motion отключает scale/пульсацию;
- крупные числа читаются VoiceOver как длительность, а не набор цифр.

## Каталог компонентов

| Компонент | Назначение |
|---|---|
| План блоков | цель, длительность и порядок выступления |
| Рабочий таймер | текущий блок, общий прогресс, метка момента |
| Временная шкала | сравнение плана и факта |
| Finding-row | объяснимый слабый фрагмент |
| Moment detail | контекст и повтор одного места |
| Session row | локальная история без облачного статуса |

## Медиа: только плейсхолдер

Контентные изображения не генерируются. Места для импортированного пользователем видео обозначаются системным `.ph`; графики времени и waveform рисуются кодом, потому что являются данными интерфейса.

## Экран → визуальное решение

- `today` — один план и одно главное действие;
- `setup` — форма без декоративных карточек;
- `frame` — камера с минимальным overlay;
- `recording` — таймер и текущий блок;
- `analysis` — шкала, метрики и один вывод;
- `moment` — локальный контекст слабого места;
- `history` — компактный список попыток;
- `settings` — grouped list с приватностью и данными.

## Четыре ловушки CSS и как они закрыты

1. Все классы концепта имеют префикс `rh-`.
2. Корни экранов не переопределяют ядровой `display:none`.
3. Визуальные носители не используют опасный шорткат `background` поверх media-класса.
4. Компонентные отступы не сбрасывают ядровые утилиты шорткатом `margin`.
