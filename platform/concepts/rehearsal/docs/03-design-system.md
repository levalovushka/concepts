# Дизайн-система

- Фон: `#111216`, поверхность: `#1b1d22`, акцент: `#ff6b5e`.
- Таймеры и числа используют Geist Mono и tabular numbers.
- Одна крупная кнопка на шаг; минимум карточек.
- Места для контентных изображений обозначены системным плейсхолдером `.ph`.
- Все подписи написаны обычным регистром; `text-transform` не используется.
