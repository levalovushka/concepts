# Визуальный аудит

- Все экраны, включая вход, на тёмной оболочке `.vkd`; светлых поверхностей нет.
- Акцент только синий ВК; прежний красный `#ff6b5e` и моноширинный Geist Mono убраны.
- На экранах входа нет системных алертов доступов.
- Три корня под таб-баром: «Главная», «Подписки», «Профиль».
- Каждый отказ показывает рабочий fallback на том же экране.
- Кадров нет: видео прогонов и уроков — плейсхолдер `.ph`.
- Тест, линтер, `audit` и `audit:grid` зелёные.
