# Визуальный аудит

- На экранах номера и SMS-кода нет системных алертов доступов.
- IA линейная; таб-бар и три одинаковых раздела отсутствуют.
- Каждый отказ показывает рабочий fallback на том же экране.
- Надписи не используют принудительный верхний регистр.
- Контентные визуалы заменены системным плейсхолдером `.ph`.
- Состояние нажатия меняет `scale` до 0.96 с точечным transition.
