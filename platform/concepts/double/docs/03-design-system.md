# Дизайн-система

## Характер

«Дубль» — спокойный инструмент для точной практики, а не социальная видеолента. Знакомая грамматика мобильного VK-сервиса проявляется в компактной шапке, медиаконтенте первым слоем, устойчивой нижней навигации и системных sheet/picker. Самостоятельность бренда создают холодный рабочий фон, фирменный индиго и цикл «фаза → измерение → короткий повтор».

## Токены

- Рабочий фон: `#f4f5f7`; поверхность: `#ffffff`; основной текст: `#181a1f`; вторичный: `#747b87`.
- Иммерсивные экраны: `#0d0e12`; вторичная тёмная поверхность: `#202228`.
- Единственный продуктовый акцент: `#3478dc`; сильное состояние: `#2469cf`; светлая подложка: `#eaf2ff`; success: `#249b63` только для результата.
- Системный стек San Francisco — интерфейс и заголовки; IBM Plex Mono — проценты, длительность, BPM и фазы. Минимум текста — 11 pt.
- Базовая сетка — 4 pt, рабочие горизонтальные поля — 16 pt. Контролы: минимум 44×44 pt; основные кнопки — 52 pt.
- Радиусы: 12–16 pt у контролов, 16–18 pt у поверхностей и видео, круг только для записи/воспроизведения.

## Композиции

- Root tabs: «Практика», «Движения», «Прогресс», «Профиль»; tab bar занимает 83 pt вместе с нижней safe area.
- Светлые root-экраны используют плотные списки и медиасетки без внешних бордеров. Строки разделяются только локальными inset-линиями.
- Референс, камера, повтор и фон — тёмные полноэкранные поверхности без tab bar. Back/close всегда имеет зону 44 pt.
- Камера показывает один ghost overlay, таймер и миниатюру референса. Разбор использует синхронный split и ровно одну выделенную слабую фазу.
- Системные поверхности не маскируются под фирменные: picker остаётся светлым iOS-списком, выбор экрана — bottom sheet, фоновой счёт — Now Playing.

## Медиа и иконки

Все движения представлены последовательной серией локальных кадров одного исполнителя и одной сцены; один кадр не переиспользуется как абстрактная иллюстрация. Интерфейсные символы — только Lucide из спрайта ядра, основной размер 22–24 pt и stroke 2. Emoji и нарисованные заглушки не используются.
