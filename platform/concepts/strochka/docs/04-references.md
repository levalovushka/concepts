# Строчка — референсы паттернов

Первоисточник визуального языка один и назван прямо: набор VK-типа — `Base Kit/vk-style-visual-guide.en.md` и `design-tokens.json`. Значения в нём вытащены из Figma-переменных VKUI программно, а не сняты на глаз, поэтому опираться на них можно как на спецификацию. Второй источник — системные паттерны iOS (HIG, `kernel/ios-chrome.md`): permission-алерт, снекбар, статус-бар, локскрин, сканер документов, Now Playing и таб-бар берутся оттуда и не перерисовываются.

## Экраны ВК Музыки: что удалось и что нет

- **Скриншоты приложения разобраны.** Заказчик прислал два набора: тёмная новая ВК Музыка (главная с VK Микс, сниппеты, «Настроить VK Микс», медиатека) и светлая ВК Музыка внутри приложения ВК (экран альбома, офлайн-режим, «Собрано людьми», «Для Вас», «Обзор»). Оба набора — рабочий референс, приёмы из них перечислены ниже.
- **scrn.gallery** (`/app/vk-music`) — **прогон не выполнен**: домен заблокирован политикой в браузерной панели, прокликать переходы нельзя. Через WebFetch страница читается, но из 67 экранов публичны 10, а ссылок на изображения в разметке нет.
- **Mobbin** — прогон выполнен, но **ВК Музыки в базе нет**: вернулись Apple Music, Deezer, Epidemic Sound, Spotify Kids, WeChat. Годится для общей раскладки плеера, не для сверки с целевым приложением.

**Какую тему взяли.** Присланные наборы показывают две канонические темы: новая ВК Музыка тёмная, ВК Музыка внутри ВК — светлая, на белой странице с hairline-разделителями. Взята светлая: она такая же каноническая, а тёмная поверхность в концепте занята плеером и локскрином — теми экранами, где она работает на фичу фонового аудио, а не на настроение.

## На какие паттерны опирается прототип

| Паттерн | Где применён | Откуда взят |
|---|---|---|
| **Cell / Rich Cell** — ведущая иконка или миниатюра, заголовок с подписью, значение или шеврон справа | все списочные экраны (`.st-list` + `.row` ядра) | Base Kit §6, Cell / Rich Cell |
| **Hairline `separator.primary` во всю ширину** между ячейками, перед первой строкой разделителя нет | те же списки | Base Kit §6 Separator, §9 Messenger, пункт 4 |
| **Group Header** — заголовок секции над списком | `.st-sec` на всех экранах | Base Kit §6, Group Header/Footer |
| **Search-пилюля** с лупой слева на `background.secondary` | `notes` (`.searchfield` ядра) | Base Kit §6 Search + §9 Messenger, пункт 2 |
| **Content Badge** — цветной текст-чип статуса | `.st-flag`: «шатко», «купюра т. 33–40», «переснять» | Base Kit §6, Badge / Content Badge |
| **Badge / Counter** — красная точка у строки с новым | строка «Дополнения» на `program` (`.row-dot` ядра) | Base Kit §6 |

| **Радиус контрола 10, карточки 16** | кнопки, `.st-quiet`, `.st-np` | Base Kit §5 |
| **Стат-ряд колонками с разделителями сверху и снизу** | `journal` (`.st-stats`) | Base Kit §9, Profile, пункт 4 |

| **Ячейки OTP** — четыре квадрата, заполненные и активный | `code` (`.otp-cell` из ядра) | iOS, общий для всех концептов вход по номеру |
| **Сегментированные разделы с подчёркиванием** — «Главная · Медиатека · Обзор» | `program`: Номера · Дополнения · Загрузки (`.segbar` ядра) | Присланные экраны ВК Музыки, светлая тема |
| **Заголовок секции со ссылкой «Показать все» + горизонтальная лента** | `program`, `piece`, `notes` (`.sec-head` / `.hscroll` ядра) | Присланные экраны: «Музыканты для Вас», «Подборки», «Новые альбомы» |
| **Цветная плитка-вход с крупным словом** — «Сегодня», «Неделя», «Для вас», «Снippets» | `program`: «Ноты с репетиции», «Все вместе» (`.st-card`) | Присланные экраны обеих тем + Base Kit §7 (декоративный набор градиентов) |
| **Градиентный герой с круглой кнопкой** — «Слушать VK Микс» | `program`, `notes` (`.st-hero-card`) | Присланные экраны, тёмная тема; перенесено на светлую страницу |
| **Экран альбома** — обложка по центру, название, автор со шевроном, жанр и год, ряд из кнопки воспроизведения и двух статусов, нумерованный список | `piece` (`.st-alb`, `.st-idx`, `.st-dur`) | Присланный экран альбома «Sosa Muzik» |
| **Мини-плеер над таб-баром** — обложка, две строки, пауза, «ещё» | все корни вкладок (`.miniplayer` ядра) | Присланные экраны обеих тем |
| **Центрированный герой** — крупная круглая кнопка по центру, заголовок под ней, подпись, пилюля-настройка | `program`, `notes` (`.st-hero-play`, `.st-hero-pill`) | «Слушать VK Микс» во всех трёх наборах тёмной темы |
| **Сетка 2×2 малых плиток сразу под героем** — «Мои треки 1240 всего», «Недавнее» | `program` (`.st-mini-grid`) | Промо «Новая VK Музыка» и экран Марии |
| **Полоса внутри героя на месте волновой формы** | `program` (`.st-hero-ruler`) — четыре сегмента по числу тактов в буквах, штрихи внутри = такты | Приём взят из «Микс по треку» и VK Микса, где фон блока — waveform. Волна у нас была бы декором, а такты — данными |
| **Строка-действие акцентом над списком** — «⤮ Перемешать все» | `program`: «Слушать подряд, альт · 36:42» (`.st-act`) | Экран альбома «Sosa Muzik», светлая тема |
| **Иконка состояния перед длительностью** — `⏱2:40`, `↻2:06` | номера программы (`.st-dur.is-ready`) | Тот же экран альбома |
| **Строка с длительностью справа** | номера программы, репетиционные буквы (`.st-dur`) | Присланный экран «Обзор» |
| **Линейка тактов по репетиционным буквам** | `player` (`.st-ruler`) | **не из Base Kit и не из мобильных продуктов**: это раскладка репетиционной цифры в партитуре. Прямого референса не нашлось, потому что задачи «показать 96 тактов четырьмя буквами» в аудиоплеерах не бывает |

### Приёмы, взятые сознательно как есть

Второй концепт репозитория на этом же визуальном языке отстроился от первоисточника серой страницей под белыми карточками, полным отказом от разделителей и радиусом 8. Здесь всё три пункта взяты **как в наборе** — белая страница, hairline, радиус 10. Причина простая: отстройка одним и тем же приёмом дважды перестаёт быть отстройкой, а различать два концепта должны акцент, гарнитура и предметные компоненты, а не повторный трюк с фоном.

### Приёмы, от которых отказались после разбора присланных экранов

| Приём | Почему не взят |
|---|---|
| **«…» в конце каждой строки** вместо шеврона — так устроены все списки в обеих темах | «…» открывает контекстное меню, которого в статичном прототипе нет: это был бы мёртвый контрол на каждой строке. Шеврон стоит там, где строка действительно ведёт на экран |
| **Аватар и имя пользователя в шапке** — «Даниил ›», «Милена ›», «Мария ›» | Учётной записи в концептах нет, есть номер телефона. Поставить имя означало бы придумать человека |
| **Список в две колонки с горизонтальным скроллом** — три строки в колонке, вторая выглядывает справа («Новинки», «Мои треки») | Приём завязан на жест, а прототип статичный: на PNG видно только обрезанную вторую колонку, и это читается как дефект вёрстки, а не как приём |
| **Разноцветные плитки** — оранжевая «Сегодня», жёлтая «Радостно», красная «Тренировка» | Правило платформы: один акцент. Градиенты держатся в одном семействе тона |

## Что осознанно не копируем

| Что | В первоисточнике | У нас | Почему |
|---|---|---|---|
| **Вордмарк и брендовая капсула в верхней строке** | пилюля со знаком в строке статус-бара | нет ни на одном экране | В первоисточнике она живёт в строке статус-бара, а его рисует ядро. Отдельный ряд под статус-баром изображал бы элемент интерфейса, которого в сборке не существует |
| **Ряд сторис** | круги 52–56 с акцентным кольцом | нет | Ни сторис, ни чужого контента в концепте нет |
| **Карточка поста и ряд действий** | лайк / комментарий / репост | нет | UGC вырезан на фазе 4 |
| **Пятнадцать акцентных цветов** | палитра для статусов и тегов | три состояния: акцент, серый, оранжевый-предупреждение | Второй акцент запрещён правилом платформы |
| **Цветные плитки меню** | двухтоновый градиент | нет | Раздела «Меню» нет; вкладок три |
| **Swipe actions** | на ячейках | нет | Прототип статичный, жест на PNG не проверяется — значит не заявляется |
| **Elevation 1/2/3** | система теней | нет теней в контенте | Тени только там, где они системные: `.st-np` и `.st-notif` на локскрине держатся blur’ом, а не высотой |
| **Grid avatar и инициалы** | до четырёх фото, инициалы как fallback | нет | Аватаров нет вовсе: людей в концепте не показываем, показываем состав партии числом |
| **Тёмная тема интерфейса** | полный второй набор токенов (§11) | нет | Страница залочена в светлую. Значения §11 использованы точечно — на двух тёмных поверхностях (`player`, локскрины), а не как вторая тема |

## Чего избегаем

- **Капсульные кнопки Apple.** В ядре есть `--r-btn: 9999px`; внутри `.screen` он переопределён на 10px — значение первоисточника.
- **Второй акцентный цвет.** Голоса различаются не цветом, а тем, что свой акцентный, остальные серые.
- **Свои SVG-пути.** Все глифы — из спрайта Lucide; нет иконки — она заводится в `gen-icons.mjs` и ядре.
- **Иконка `clock` в таб-баре.** Активная вкладка в ядре заливается (`fill: currentColor`), и `clock` превращался в глухой круг. Журнал получил `book-open`, программа — `layout-grid`.
- **Диплинки** — Universal Links, `associated-domains`, приём чужих ссылок. Правило платформы: не проектируем, ключ не заявляем.
- **Иллюстрации и стоковые фото.** Медиа — только плейсхолдер `.ph`.

## Что проверить, когда появится доступ к галереям

| Что искать | Зачем |
|---|---|
| ВК Музыка: очередь воспроизведения и полноэкранный плеер | В присланных наборах полноэкранный плеер есть только в тёмной теме и без списка очереди — сверить нечем |
| Приложения для хоров и оркестров (Choir Genius, MuseScore, forScore, Newzik) | `piece` и `player`: как показывают партию одного голоса и репетиционные цифры |
| forScore, Newzik: библиотека партитур | `notes`: раскладка «страницы по произведениям» и что делают с криво снятым разворотом |
| Document scanner в Notes, Dropbox, Scanner Pro | `camera`: подпись счётчика страниц и кнопка сохранения многостраничного скана |
| Photo library auto-selection («этот день», «снимки рядом») | `import`: как объясняют, что приложение само обошло библиотеку, и как дают отменить |
| Плееры с A–B петлёй (Amazing Slow Downer, Anytune) | `player`: как показывают границы повторяемого фрагмента |
| Экраны «что нового в паке» в офлайн-приложениях | `releases`: раскладка истории выпусков со состоянием загрузки |
