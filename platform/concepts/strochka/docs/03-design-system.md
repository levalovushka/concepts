# Строчка — дизайн-система

Язык взят из Base Kit и собран как мимикрия VK Музыки: тёмная музыкальная оболочка, знакомая композиция библиотеки и плеера, единый VK blue для действий и белые selected chips. Системный iOS-хром берётся из ядра и в концепте не переопределяется.

## Токены концепта

| Токен | Значение | Где работает |
|---|---|---|
| `--accent` / `--accent-fill` | `#0077FF` | Заливка главной кнопки, интерактивный текст, прогресс и active tab icon |
| `--accentDark` | `#0077FF` | Тот же системный акцент на тёмной поверхности |
| `--st-bg` / `--st-panel` | `#19191B` / `#232326` | Фон и поднятые поверхности VK Музыки |
| Selected chips | `#F5F5F7` / `#161618` | Выбранный сегмент или фильтр без второго синего CTA |
| `--st-sub` | `#6D7885` | Второстепенный текст, 4.6:1 на белом |
| `--st-mute` | `#79818C` | Третичный: мета-строки списка. Исходный `#99A2AD` набора давал 2.4:1, а через третичный тон здесь идёт почти вся мета |
| `--st-line` | `#D7D8D9` | `separator.primary` первоисточника |
| `--st-warn` / `--st-warn-bg` | `#8A5300` / `rgba(248,160,28,.18)` | «Шатко», «переснять». Сам `#F8A01C` текстом давал 2.1:1, поэтому носитель разделён: заливка одна, текст другой |
| `--st-ink-dark` | `#17090D` | Подложка под белой кнопкой воспроизведения |
| `--face` | `Inter` 400–700 | Вся типографика интерфейса |
| `--mono` | `IBM Plex Mono` 400–500 | Числа предметной области: такты, буквы, таймкоды, даты, минуты |
| `--r-btn` (в `.screen`) | `10px` | Радиус контрола первоисточника (§5) вместо капсулы ядра |
| Медиа-плитки | Предметные обложки и нейтральные затемнения | Цвет живёт в обложке; интерфейс поверх неё не создаёт второй брендовый акцент |

Моноширинный здесь не украшение: в этой предметной области чисел больше, чем слов — «т. 41–74», «с буквы В», «25.II», «2:14», «96 тактов». Разделение гарнитур делает данные читаемыми как таблицу, а не как прозу.

## Отстройка от первоисточника

| Что | В первоисточнике | У нас | Почему |
|---|---|---|---|
| Акцент | VK blue | `#0077FF` | Действия и навигация воспринимаются как часть семейства VK Музыки |
| Гарнитура | SF Pro Text / Roboto | Inter | §8 называет Inter одним из двух примеров замены |
| Радиус контрола | 10pt iOS | 10pt | **Взято как есть.** Второй концепт на этом же языке ушёл в 8pt; отстраиваться дважды одним и тем же приёмом смысла нет |
| Фон страницы | Тёмная оболочка VK Музыки | `#19191B` | Единая среда с остальной музыкальной мимикрией |
| Разделители | hairline `separator.primary` между ячейками | hairline во всю ширину, отступ слева 16 | Взято как есть: у соседнего концепта разделителей нет вовсе, и это была его отстройка, а не общая |
| Плотность ячейки | Headline 16/20 | 16/20 внутри `.st-list` | Ячейка ядра — iOS 17/22. Внутри списков концепта возвращена плотность первоисточника |
| Заголовок раздела | Title 3 17/22 по центру | Large title 34/41 слева (из ядра) | Корни вкладок — системный iOS. Здесь первоисточник проигрывает системе: заголовок вкладки в iOS большой |
| Цветные плитки меню | двухтоновый градиент, 15 акцентных цветов | нет | Второго акцента в концепте нет вовсе. Голоса различаются **не цветом**, а тем, что свой голос акцентный, а три остальных серые — это и есть продуктовая мысль |
| Иконки | SF Symbols | спрайт Lucide из ядра | Итоговый файл самодостаточен, в системный шрифт он ходить не может |

## Свои компоненты

Всё с префиксом `pa-`; в `base.css` такого префикса нет, поэтому коллизия имён (первая из трёх ловушек CSS) исключена по построению.

| Класс | Что это |
|---|---|
| `.st-ruler` / `.st-seg` | Линейка тактов: 96 тактов, разбитых репетиционными буквами. Ширина сегмента пропорциональна числу тактов в букве (24 / 16 / 34 / 22), внутри активного — линия проигранного. Это данные экрана, а не визуал |
| `.st-key` / `.st-let` | Носители навигации по произведению: голос (С А Т Б, сквиркл) отвечает «какая строчка», репетиционная буква (круг) — «откуда» |
| `.st-flag` | Чип состояния: «уверенно», «шатко», «купюра т. 33–40», «переснять», «страниц нет» |
| `.st-num` / `.st-date` | Моноширинные ведущие: номер в программе, дата выпуска дополнения |
| `.st-notes` / `.st-note` | Пометки с розданной ксерокопии: слева такт или буква, справа то, что написано карандашом |
| `.st-np` / `.st-notif` | Now Playing и уведомление на локскрине |
| `.st-frame` / `.st-cam-read` | Рамка системного сканера страниц и строка распознанных тактов |
| `.st-weeks` / `.st-week` | Столбцы минут по неделям в журнале |
| `.st-page-thumb` | Миниатюра страницы: портрет 46×61 вместо пейзажной миниатюры ядра — страница нот вертикальная |
| `.st-quiet` | Блок fallback при отказе доступа |
| `.st-hero-card` | Градиентный герой раздела: киккер, крупная строка состояния, продолжение с буквы. На «Нотах» в него встроен триггер доступа к «Фото» |
| `.st-card` (`g1`, `g2`) | Плитки-входы на градиенте: капсовый киккер сверху, название и подпись у нижнего края |
| `.st-cc` | Карточка горизонтальной ленты: 128×128 плейсхолдер, название, моноширинная подпись |
| `.st-alb` | Шапка номера в раскладке экрана альбома: обложка 148, название, автор со шевроном, моноширинная мета, ряд из кнопки и двух статусов |
| `.st-idx` / `.st-dur` | Номер в программе и длительность — как в списке треков альбома |

## Правила копирайта

Выведены из разбора: первая версия несла в мете предложения с глаголами, и от этого экраны читались как документация к себе.

| Правило | Плохо | Хорошо |
|---|---|---|
| **Мета-строка — данные, не фраза.** Числа и существительные, до четырёх слов. Глагол в мете — признак объяснения | «Шапка с автором и опусом, отсюда читается номер» | «шапка с автором и опусом» |
| **Один объект — один термин.** Страница — то, что на бумаге; снимок — то, что в галерее. «Кадра» нет | «12 кадров», «12 снимков», «12 страниц» об одном | «12 снимков» везде |
| **Один факт — одно место.** Счётчик найденного живёт на «Нотах»; в разборе — только отметка выбора | «12 снимков ждут разбора» → «8 от 18-го и 4 от 25-го» → «12 снимков за 18 и 25 февраля» | «12 снимков без номера» на «Нотах», «Отмечено 9 из 12» в разборе |
| **Списки не пишутся по шаблону.** Если у соседних строк одинаковая синтаксическая форма и они отвечают на один вопрос — это заполненная форма, а не данные | «вступление альтов на „раз-и“ после паузы» · «под соло тенора, альт вторым планом» · «не открывали» | «24 такта · 1:02» · «16 тактов · 0:42» · «22 такта · 0:54» |
| **Подвалов-объяснений нет.** Уточнение числа — можно, оправдание решения — нет | «Дополнения приходят паком целиком, чтобы „с буквы В“ означало одно и то же у всех» | снято |
| **Fallback — две короткие фразы.** Что пропало и что осталось | «Нет доступа к камере — съёмка убрана. Буквы и такты идут с записью, страницы добираются из снимков в галерее.» | «Нет доступа к камере. Страницы можно взять из снимков в галерее.» |
| **Доменное знание остаётся**, если без него фича непонятна | — | «дыхание перед В, а не на В» |

## Правила строки списка

| Правило | Почему |
|---|---|
| **Один элемент на правом краю.** Приоритет: незавершённое состояние загрузки → длительность → чип готовности | Длительность и галочка «скачано» рядом — два разных сообщения в одной точке; правый столбец перестаёт читаться |
| **Инсет разделителя = левый край текста.** Под ведущий индекс 18 — 46, под букву 30 — 58, под дату 34 — 62 | Значение ядра (60) рассчитано на иконку 29; с узким индексом разделитель начинался в воздухе |
| **Заголовок секции один на все экраны** — `.sec-head` с `.t-headline`; значение справа серое (`.is-plain`), акцентное только то, что нажимается | Мелкий серый заголовок и крупный чёрный на одном экране читались как две системы, а серое «37 страниц» акцентом выглядело ссылкой |
| **Три вида чипа**: нейтральный (данные), `is-soft` (внимание), `is-none` (пусто) | Пяти видов на 14 экранов никто не различает: «купюра» серым читалась так же, как «уверенно» |

## Медиа

Своих ассетов у концепта нет: `media.mjs` создаёт `assets/media` и оставляет каталог пустым. Всё, что было бы фотографией — страница нот, снимок с репетиции, обложка номера в Now Playing, — плейсхолдер `.ph` (`.ph.on-dark` на тёмном).

Данные, нарисованные кодом, — линейка тактов, столбцы недель, рамка сканера — это содержимое экрана, без которого фича непонятна, а не визуал.

Отдельно проверено правило «`.ph` не герой композиции»: первая версия экрана страниц показывала сетку 2×2 из крупных плейсхолдеров на пол-экрана. Заменено на список строк с портретными миниатюрами, где вокруг миниатюры — данные страницы: диапазон тактов, что на ней карандашом, чего не хватает.

## Три ловушки CSS

1. **Коллизия имён.** Все свои классы с префиксом `pa-`; проверяется `lint-concept.mjs --kernel`.
2. **Шорткат `background`.** В `styles.css` не используется ни разу — только `background-color`.
3. **Шорткат `margin`.** Не используется — только `margin-top` / `margin-bottom`, иначе гасятся утилиты `.mt*` ядра.
