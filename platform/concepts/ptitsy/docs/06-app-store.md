# Карточка App Store

**Название:** Птицы — полевой аудиогид
**Подзаголовок:** Узнать вид и сравнить голос
**Категория:** Reference / Education
**Возраст:** 4+
**Цена:** Бесплатно, без встроенных покупок

Для review используется номер +7 900 000-00-00 и код 0000. Фото не собираются: пользователь отдаёт один файл через PHPicker, распознавание идёт локально. Трекинга, аналитического профиля и рекламы нет.

Ревьюеру: войти тестовым номером, нажать «Определить птицу», затем отдельно проверить камеру и выбор снимка. Голос запускается из карточки зяблика. Push находится в «Сезонных выпусках».
