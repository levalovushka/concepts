# Птицы — дизайн-система (концепт)

## Направление

Визуальный язык соединяет бумажный полевой определитель и спокойный системный интерфейс iOS. Сезонная поверхность тёплая и редакционная, камера функциональная, плеер тёмный и не конкурирует с природным звуком.

## Токены

### Цвет

| Роль | Токен | Значение |
|---|---|---|
| Бумажный фон | `--pt-cream` | `#f6f3e8` |
| Основной текст | `--pt-ink` | `#18362a` |
| Акцент | `--pt-moss` | `#285e47` |
| Сезонные поля | `--pt-sage`, `--pt-sky`, `--pt-sand` | шалфей, небо, песок |

### Типографика

Основной интерфейс — Manrope. Служебные сезонные подписи и полевые данные — моноширинный системный токен `--mono`. Числа используют tabular figures там, где меняются во времени.

### Радиусы

Сезонная карточка — 28 px, крупные поверхности — 18 px, контролы — 10–13 px. Крупный радиус закреплён только за редакционным контентом и не переносится на системные picker и camera chrome.

### Отступы и safe areas

Основная горизонталь — 20 px. Интерактивные цели не меньше 44 pt. Кастомные шапки начинаются ниже `--safe-top`, нижние действия учитывают `--safe-bottom`.

## Требования HIG, которые прототип обязан соблюдать

- системные разрешения появляются после жеста, объясняющего действие;
- камера и picker визуально отличаются от контентных экранов;
- элементы управления плеером имеют системные значения и доступны с локскрина;
- Dynamic Type и VoiceOver не должны зависеть от цвета карточки;
- reduce motion убирает наклон/scale сезонной колоды;
- отказ показывает рабочую альтернативу на текущем маршруте.

## Каталог компонентов

| Компонент | Где используется | Правило |
|---|---|---|
| Сезонная колода | `season` | один главный вид, следующая карта только намечена |
| Метод определения | `identify` | камера, Фото и справочник равноправны |
| Результат распознавания | `result` | вероятность вторична, признаки первичны |
| Редакционная карточка | `bird` | название, сезон, признаки, голос |
| Полевой плеер | `player` | крупный play/pause, Now Playing, без feed |
| Алфавитный ряд | `library` | ручной путь при отказе в доступах |

## Медиа: только плейсхолдер

Контентные фотографии не входят в концепт. Их место показывает ядровой `.ph`; цветные поля кодируют сезон и структуру, но не притворяются готовой иллюстрацией птицы.

## Экран → визуальное решение

- вход — светлая системная форма без продуктовых разрешений;
- сезон — тёплая колода с одним доминирующим выбором;
- определение — белый sheet с тремя понятными путями;
- камера — тёмная fullscreen-поверхность с одной рамкой;
- карточка вида — редакционный вертикальный ритм;
- плеер и локскрин — тёмная среда, где главный объект звук;
- библиотека — плотный, но спокойный алфавитный список.

## Четыре ловушки CSS и как они закрыты

1. Классы концепта имеют префикс `pt-` и не сталкиваются с ядром.
2. В медиа-носителях не используется шорткат `background`, способный стереть изображение.
3. Компонентные отступы не глушат ядровые утилиты шорткатом `margin`.
4. Корневые `.screen` не получают собственного `display`, поэтому скрытые экраны не проявляются одновременно.
