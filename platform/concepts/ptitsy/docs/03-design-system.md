# Дизайн-система

- Холст: бумажный крем `#f6f3e8`.
- Основной тон: мох `#285e47`.
- Сезонная подборка: шалфей, небесный и песочный.
- Типографика: Manrope; служебные сезонные подписи — IBM Plex Mono.
- Радиусы подборки крупнее системных контролов: 28 / 18 / 13.
- Места для контентных изображений обозначены системным плейсхолдером `.ph`.
- Все тексты в обычном регистре; `text-transform` не применяется.
- Основная навигация — сегмент «Сезон / Справочник» и контекстные переходы. Tab bar отсутствует.
