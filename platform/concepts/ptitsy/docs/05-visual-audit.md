# Визуальный аудит

- Вход по номеру и SMS-коду не содержит системных запросов доступов.
- Камера и Фото спрашиваются только из режима «Определить».
- После отказа видны два рабочих пути: другой источник и автономный справочник.
- Четыре системные возможности имеют достижимые сценарии.
- Сезонная колода, камера, карточка, плеер и библиотека имеют разную композицию.
- Контентные изображения заменены системным плейсхолдером `.ph`.
- Текст не набран капсом и не преобразуется через CSS.
- Фоновое аудио объяснено полевым контекстом и имеет Now Playing.
