# Архитектура

## Локальное ядро

- `SeasonPackRepository` читает JSON из bundle.
- `BirdClassifier` запускает Core ML/Vision на кадре или выбранном изображении.
- `VoicePlayer` воспроизводит bundled AAC и публикует Now Playing.
- `ObservationStore` сохраняет отметки в SwiftData.
- `PhoneAuthService` использует SDK провайдера; токен хранится в Keychain.
- `PermissionsService` — единственная точка системных запросов.

## Внешние границы

Собственного API нет. SDK провайдера обслуживает вход по номеру, а `aps-environment` — одно редакционное уведомление о выпуске.

## Offline-проверка

После входа без сети доступны сезонная подборка, определение, справочник, карточки, голоса и история локальных отметок. Недоступно только получение нового push; это не блокирует продукт.

## Матрица доступов

Каждая строка читается так: пользователь делает жест — система спрашивает — при отказе остаётся рабочий путь.

<!-- @generated:perm-matrix -->
| Ключ | Жест пользователя | Экран | Если отказ | Риск Review |
|---|---|---|---|---|
| `NSCameraUsageDescription` | «Навести камеру» | Определить птицу | Можно выбрать снимок или найти вид в автономном справочнике | Низкий |
| `NSPhotoLibraryUsageDescription` | «Выбрать снимок» | Определить птицу | Можно использовать камеру или открыть автономный справочник | Низкий |
| `UIBackgroundModes: audio` | «Слушать голос» | Зяблик | Карточка вида и короткое прослушивание на открытом экране остаются доступны | **Условный** — AVAudioSession .playback, MPNowPlayingInfoCenter и remote-команды |
| `aps-environment` | Свитч «Новый сезонный выпуск» | Сезонные выпуски | Наличие выпуска всегда можно проверить вручную на этом экране | **Условный** — APNs-кампания готового провайдера публикаций; собственного API приложения нет |
<!-- @end -->

## Информационная архитектура

Дерево выведено из разметки экранов, а не нарисовано руками: рукописная схема расходится с прототипом первой же правкой.

<!-- @generated:ia-tree -->
```
Вход по номеру (phone) — старт, без таб-бара · открывается: старт
    └─ Код из SMS (code) — push · открывается: «Получить код»
        ├─ Неверный код (codefail) — push · открывается: «Код из четырёх цифр»
        └─ Сейчас рядом (season) — сезонная колода · открывается: «Войти», «Сезон»
            ├─ Определить птицу (identify) — bottom sheet · открывается: «Определить птицу» · camera, photo
            │   ├─ Навести камеру (camera) — fullscreen camera · открывается: «Навести камеру» (camera)
            │   ├─ Выбрать снимок (photos) — system picker · открывается: «Выбрать снимок» (photo)
            │   └─ Похоже, зяблик (result) — recognition result · открывается: «Определить», «Готово» …
            ├─ Зяблик (bird) — вид · editorial detail · открывается: «Зяблик», «Пеночка-весничка» …, «Юрок», «Зеленушка» … · audio
            │   └─ Голос зяблика (player) — fullscreen audio · открывается: «Песня самца», «Позывка» … (audio)
            │       └─ Экран погас (background) — system Now Playing · открывается: «Продолжить с погасшим экраном»
            └─ Сезонные выпуски (releases) — settings detail · открывается: «Сезонные выпуски» · push

Справочник (library) — алфавитная библиотека · открывается: «Справочник», «Искать по признакам»
```

## Граница «без бэкенда»

<!-- @generated:backendless -->
| Требовало бы сервера | Решение без сервера |
|---|---|
| Каталог видов | Версионированный сезонный пакет JSON входит в приложение |
| Справочник и голоса | Метаданные и сжатые записи поставляются в локальном bundle |
| Распознавание | Core ML/Vision выполняет классификацию на устройстве |
| История наблюдений | SwiftData хранит отметки локально, без профиля и синхронизации |
| Сезонное уведомление | Одна редакционная APNs-кампания готового провайдера; своего API нет |
| Вход по номеру | SDK провайдера аутентификации; токен хранится в Keychain |
