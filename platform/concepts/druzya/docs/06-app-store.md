# Друзья — app-store

Заполняется по PLAYBOOK.md.

Карточка стора — третья сверка концепта: App Store, Info.plist и privacy-лейблы обязаны говорить одно и то же. Источник значений — блок `appStore` в `concept.json`; лимиты (Name 30 / Subtitle 30 / Promotional Text 170 / Keywords 100) проверяет `lint-concept.mjs`.

Обязательно: демо-доступ для ревьюера (тестовый номер и код — вход по номеру есть в каждом концепте) и Review Notes, в которых для каждого доступа сказано, каким жестом ревьюер до него дойдёт.

## Актуальная серия кадров

1. `feed` — Только свои в ленте
2. `post` — Делитесь со своим кругом
3. `circles` — Разделяйте друзей по кругам
4. `profile` — Помните, когда виделись
5. `music` — Слушайте музыку вместе

Серия пересобирается из текущих продуктовых экранов; удалённые поверхности не входят в экспорт.
