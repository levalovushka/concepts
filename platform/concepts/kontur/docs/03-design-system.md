# Контур — дизайн-система

## Тезис

Рабочий контакт-лист: единая белая поверхность, почти чёрная типографика и один красный цвет для действий лаборатории.

## Палитра

- Базовая поверхность #FFFFFF; чернила #171412; вторичный текст #746E66; линия #E5E1DC.
- Акцент #B42318; мягкий акцент #FBE9E7; успех #25734D; ночной фон #171412; акцент на ночном фоне #FF5A4F.

## Шкала

- Отступы: 4, 8, 12, 16, 20, 24 pt. Боковое поле — 16 pt; корневые панели используют высоты 58 и 84 pt.
- Скругления: 10–14 pt для полей и карточек; крупные радиусы не складываются каскадом внутри одного экрана.
- Заголовок экрана: 28/34, 700; заголовок раздела: 14/20, 700; карточка: 20/26, 700; основной текст: 15/22, 500; вторичный: 13/18, 500; подпись: 11/14, 700.
- UI — Manrope; номера кадров и параметры — IBM Plex Mono.

## Компоненты и композиция

Навигация, tab bar, строка, карточка, системный лист, primary-кнопка, secondary-кнопка, переключатель, статус и иконка используют общие токены. Основное действие одно на экран. Красная заливка не используется для больших информационных карточек: активный процесс получает мягкий фон и контрастную границу. Контакт-листы разделяются светлыми промежутками без чёрной решётки. Иконки — только из общего Lucide-спрайта.
