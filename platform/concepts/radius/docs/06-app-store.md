# Радиус — App Store

Карточка стора хранится в `concept.json` и проверяется линтером. Набор `vk-video` используется полностью: 10 из 10 доступов.

## Путь ревьюера

1. Войти с номером `+7 900 000-00-00` и кодом `0000`.
2. На экране бесплатной версии продолжить с рекламой — здесь появляется ATT.
3. На главной выбрать «Рядом · 20 мин» — геопозиция.
4. Открыть первое видео:
   - телевизор — локальная сеть;
   - «Сохранить» — добавление в медиатеку;
   - «В фоне» — background audio;
   - «Ссылка» — associated domains.
5. На вкладке «Создать»:
   - «Снять видео» — камера и микрофон;
   - «Из медиатеки» — чтение Photo Library.
6. На вкладке «Подписки» включить «Новые видео» — push notifications.

## Приватность

Грубая геопозиция используется только для расстояния до мест и не применяется для рекламы. Видео остаётся локальным черновиком до явной публикации. IDFA передаётся рекламному SDK только после разрешения ATT.
