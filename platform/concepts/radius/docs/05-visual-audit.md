# Радиус — визуальный аудит

Проверено 18 экранов: вход, главная и геолента, просмотр и системные состояния, клипы, создание, подписки, канал, профиль и сохранённые.

## Выполнено

- Все пиктограммы интерфейса используют Lucide-спрайт ядра.
- Активные иконки таббара не получают случайную тяжёлую заливку.
- Таббар клипов закреплён снизу и не занимает верхнюю safe area.
- Интерактивные области не меньше 44×44.
- Элементы не выходят за горизонтальные границы устройства.
- Минимальный размер вторичного текста — 11 px.
- Интерактивный коралловый затемнён до `#D64028`: белый текст проходит AA с отношением 4.54:1.
- Вторичный серый текст использует `#666666`: 5.74:1 на белом.
- Горизонтальная полоса действий плеера имеет fade на краю и показывает, что список продолжается.
- Фотографии не содержат сторонних логотипов или текста и сгенерированы специально для концепта.

## Автоматические проверки

- `npm run audit -- radius` — чисто.
- `npm run lint -- radius` — расхождений нет.
- `npm run test -- radius` — успешно.

## Ручная проверка

На ключевых скриншотах проверены: визуальный центр, порядок чтения, safe areas, контраст поверх медиа, обрезка текста, единообразие радиусов, плотность метаданных и положение таббара.
