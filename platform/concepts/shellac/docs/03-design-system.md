# Шеллак — дизайн-система

## Идея визуального языка

Шеллак и бумага. Диск — не чёрный, а тёмно-коричневый: смола с наполнителем, при свете отдаёт в тёплое. Этикетки выгоревшие, с пятнами и потёртостями. Стол — дерево. Всё остальное — системный iOS без самодеятельности: тёмные иммерсивные поверхности для плеера и камеры, светлые grouped для списков и настроек.

Акцент один — жжёная амбра `#a8631d`. Она же цвет лака, поэтому не спорит с медиа, а продолжает его.

## Токены

| Токен | Значение |
|---|---|
| `--accent` | `#a8631d` · `#e8a75e` в тёмной теме |
| `--accent-fill` | `#a8631d` — заливки и текст акцентом на светлом |
| `--refused` | `#9c3f2e` — подписи fallback при отказе |
| `--face` | Geist 400 / 500 / 600 / 700 |
| `--mono` | Geist Mono 400 / 500 — матричные номера, таймкоды, ключи |
| `--device-w` | 390px, высота 844 (iPhone 13/14) |
| `--safe-top` / `--safe-bottom` | 47px / 34px |
| `--r-card` / `--r-panel` / `--r-device` | 10 / 12 / 40 |

Радиусы, высоты строк, навбар, таб-бар, свитчи, сегменты, системный алерт и snackbar берутся из ядра (`kernel/base.css`), собранного по `components.html`. Своих аналогов системных контролов в концепте нет.

## Где моноширинный

Матричный номер — главные «данные» этого продукта: по нему сторона опознаётся однозначно. Он всегда моноширинный, с табличными цифрами:

- `.matrix` — номер в карточке и списке
- `.mono-chip` — номер или ключ в плашке (`shellac.app/want`, `PHPicker`)
- `.read-row span` — значения в таблице «прочитано с этикетки»
- `.lv-time`, `.pl-remain` — время и остаток стороны

## Поверхности

| Тип | Экраны | Статус-бар |
|---|---|---|
| Тёмная иммерсивная | `player`, `background`, `scan` | светлый |
| Светлая grouped | `archive`, `record`, `shelf`, `copy`, `want`, `settings` | тёмный (`.dark-ink`) |
| Модальная светлая | `scanfound`, `scanfail`, `notfound`, `deeplink` | тёмный |
| Системная | `pick` (PHPicker), `web` (Safari) | тёмный |

## Медиа

Всё рисуется кодом — `concepts/shellac/media.mjs`. Стоковых фото в проекте нет, поэтому вопросов по правам не возникает. Псевдослучай детерминированный (seed), пересборка даёт побайтово тот же результат.

| Файл | Что это | Где используется |
|---|---|---|
| `d1–d6.svg` | Диск 400×400: канавки, разделители дорожек, бумажная этикетка | Обложки, превью в списках, сетка PHPicker |
| `s1–s3.svg` | Бумажный конверт с вырезом под этикетку, кольцевой след диска | Полка, фото конверта |
| `label.svg` | Крупная этикетка 520×520 с потёртостями | Кадр сканера |
| `scene-table.svg` | Стол с пластинкой и конвертом, 390×844 | Превью камеры |
| `wide-shelf.svg` | Ящик с конвертами лицом, 390×260 | Карточка «Продолжить» |
| `wide-table.svg` | Пластинка и конверт на столе, 390×260 | Широкие превью |
| `turntable.svg` | Диск на мате с тонармом, игла на первой трети стороны | Плеер |

Раскладка этикетки повторяет настоящую: лейбл дугой сверху, название над шпиндельным отверстием, исполнитель под ним, матрица и год дугой снизу. Строк по центру нет — там отверстие.

## HIG

- Хит-таргеты ≥ 44pt: утилита `.tap` подкладывает псевдоэлемент `max(100%, 44px)`.
- Safe areas 47 / 34, home indicator на каждом экране приложения.
- `prefers-reduced-motion` гасит анимации (правило в ядре).
- Статус-бар переключается на `.dark-ink` для светлых экранов — флаг `light` в спеке.
