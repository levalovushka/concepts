# Накат — референсы и доменные факты

## Что взято из предмета

Числа в интерфейсе не декоративные — они из программы подготовки водителей категории B:

| Факт | Значение | Где виден в прототипе |
|---|---|---|
| Практика | 56 часов вождения | счётчик «34 из 56» на «Занятиях», виджет |
| Теория | 134 часа программы | ведомость: «96 из 134» |
| Билеты | 40 билетов по 20 вопросов | раздел «Теория», «27 из 40» |
| Допустимо на экзамене | не более 1 ошибки из 20 | подпись у билета 11 |
| Медсправка | действует 1 год | документы: «годна до 26.07.2027» |
| Экзаменационные маршруты | публикует ГИБДД, обновляются раз в год | «Экзаменационные маршруты рядом», «обновил 3 февраля» |
| Посещаемость теории | учитывается в ведомости, пропуски отрабатываются | ведомость: «2 занятия нужно отработать» |

Города и адреса вымышленные (Кабельная, Гвардейская, площадь Победы), автошкола и номер договора — тоже. Учебные машины — Rio и Granta: типичные для автошкол, но названия используются как факт о машине, а не как реклама марки.

## iOS-практики, на которые опирается концепт

| Что | Framework | Как здесь используется |
|---|---|---|
| Звонок без обмена номерами | PushKit + CallKit | входящий поднимает приложение и рисуется системным интерфейсом; адресация по паре внутри учебной группы |
| Фоновое аудио | AVAudioSession `.playback`, MPNowPlayingInfoCenter, MPRemoteCommandCenter | разбор билета продолжается с погашенным экраном, ±15 с — с кнопок руля |
| Сканирование QR | DataScannerViewController | QR на стекле машины и QR сети класса |
| Речь на устройстве | SFSpeechRecognizer, `requiresOnDeviceRecognition = true` | расшифровка заметки и сверка проговоренного алгоритма |
| Имя текущей сети | CNCopyCurrentNetworkInfo | отметка присутствия; работает только вместе с выданной геопозицией |
| Подключение к Wi-Fi | NEHotspotConfigurationManager | параметры из QR со стены класса |
| События календаря | EventKit, full access | занятие ставится и правится при переносе — write-only своё событие найти не даёт |
| Автозаполнение | ASCredentialProviderViewController | логины учебных сервисов подставляются в Safari |
| Фоновые задачи | BGAppRefreshTask, BGProcessingTask | `app.nakat.refresh` — расписание, `app.nakat.audio` — догрузка разборов |
| Уведомления-сообщения | INSendMessageIntent + Notification Service Extension | сообщение инструктора с аватаром, проходит через Focus «За рулём» |
| Виджет | WidgetKit + App Group | следующее занятие и накатанные часы |
| Замок | LocalAuthentication | Face ID с код-паролем как запасным путём |

## Гайдлайны, под которые концепт сознательно не попадает

| Guideline | Риск | Чем закрыт |
|---|---|---|
| 2.5.4 Background modes | `voip` и `audio` — самые дорогие ключи набора | реальный CallKit-звонок и реальный playback с Now Playing; оба доступны за 2–3 тапа от старта |
| 5.1.1 Data & privacy | доступ без фичи | 20 ключей — 20 фич с жестами; два ключа набора не заявлены вовсе |
| 5.1.2 ATT | трекинг без объяснения | экран «Почему здесь реклама» до промпта, отказ ничего не отключает |
| 5.1.4 Kids | реклама в образовательном приложении | аудитория — с 18 лет, приложение не в Kids Category, рейтинг 12+ |
| 4.2 Minimum Functionality | тонкая обёртка | тест на подмену: без аудио, звонка и переноса остаётся commodity-тренажёр |
| 4.3 Spam | похожие концепты | автошкола далека и от целевого приложения, и от других концептов набора (соседская сеть) |
| 3.1.1 IAP | цифровой контент мимо IAP | внутри ничего не продаётся, курс оплачивается в кассе автошколы |

## Что осталось за границей концепта

* **Интерфейс инструктора.** Он ставит отметки и открывает окна со своей стороны; в прототипе виден только результат.
* **Экзамен в ГИБДД.** Приложение доводит до внутреннего экзамена; запись в ГИБДД делает автошкола списком группы.
* **Диплинки.** Ссылок в приложение нет, `associated-domains` не заявлен.
* **Оплата.** Ни IAP, ни платёжных форм: только строка «32 000 / 38 000 ₽» как факт из договора.
