# Накат — дизайн-система

Ядро (`kernel/base.css`) даёт системный iOS-хром: навбар, таб-бар, ячейки Inset Grouped, кнопки, свитчи, шиты, снекбар, локскрин, экран «Домой», индикатор загрузки `.dl`. Концепт добавляет только своё — под префиксом `nk-`.

## Токены

| Токен | Значение | Где |
|---|---|---|
| `--accent` | `#1e56a0` | акцент светлой темы: активные строки, прогресс, ведущие иконки фич |
| `--accent` (dark) | `#79aef5` | тёмная тема: журнал доступов, метки в плеере |
| `--accent-fill` | `#1e56a0` | заливка кнопок и плашек в обеих темах |
| `--face` | Inter | интерфейс |
| `--mono` | IBM Plex Mono | данные: часы, таймкоды, номера машин, SSID, идентификаторы задач |

Синий выбран не как «цвет бренда», а как цвет учебной таблички: он одинаково читается на белом списке и на тёмном плеере, и не спорит с системным красным (`.destructive`, календарь) и зелёным (подтверждения).

## Что моноширинным

Правило простое: **моноширинный — там, где число можно сравнить с другим числом.** `34 из 56 часов`, `41:12`, `3:18 / 8:40`, `В 412 УМ`, `AVTO4-CLASS`, `app.nakat.refresh`, `−48 dBm`, `32 000 / 38 000 ₽`. Всё остальное — Inter.

## Поверхности

| Поверхность | Экраны | Почему |
|---|---|---|
| Светлая grouped | занятия, теория, ведомость, документы, настройки | список данных, читается днём и на солнце |
| Тёмная иммерсивная | `call`, `player`, `scan`, `scanwifi`, `widget`, `lockscreen`, `background` | системные поверхности: звонок, плеер, камера, локскрин, «Домой» |
| Шит поверх экрана | `reschedule` | перенос — операция над занятием, а не отдельный раздел; за шитом виден сам экран занятия под затемнением |

## Свои компоненты

| Класс | Роль |
|---|---|
| `.nk-next` | карточка «следующее занятие» / «продолжить билет»: акцентная плашка с кикером, крупным заголовком и чипами |
| `.nk-hours`, `.prog` | счётчик часов: крупное число, полоса, три сводки под ней |
| `.nk-slot`, `.nk-slot-mini` | свободное окно: день, время, инструктор. Мини-вариант — в списке переноса |

| `.nk-cc` + `.nk-cc-face.is-data` | карточка аудио-разбора. Обложки у разбора нет — вместо неё длительность и состояние загрузки |
| `.nk-timer` | ход занятия: 41:12 из 90 минут |
| `.nk-rec`, `.nk-wave`, `.nk-quote` | запись заметки, уровень, расшифровка |
| `.nk-q`, `.nk-opt`, `.nk-sch` | вопрос билета: схема перекрёстка, варианты, выбранный |
| `.nk-pl*` | плеер разбора: обложка-плейсхолдер, полоса, ±15, темы с таймкодами |
| `.nk-np*`, `.nk-notif`, `.nk-lock-*` | локскрин: Now Playing и уведомления, включая сообщение с аватаром |
| `.nk-call*` | CallKit-подобная поверхность звонка |
| `.nk-scan-frame`, `.nk-code` | рамка сканера и матрица QR |
| `.nk-safari*`, `.nk-fillbar`, `.nk-keybar` | Safari и подстановка пароля из связки ключей |
| `.nk-sb`, `.nk-widget*`, `.nk-tech` | экран «Домой», виджет, технические строки контейнера |

| `.nk-backdrop` | экран занятия под шитом переноса |

## Плейсхолдеры и рисованные данные

Фотографий в концепте нет. `.ph` стоит там, где в жизни миниатюра или кадр: аватар в звонке, сканы документов, кадр камеры, обложка в плеере и мини-плеере.

Кодом рисуются только **данные**, без которых фича непонятна:

* `assets/media/map.svg` — карта кварталов с треком экзаменационного маршрута №3 (генератор — `media.mjs`, детерминированный seed);
* `assets/media/qr.svg` — матрица QR для сканера;
* `.nk-sch` — схема перекрёстка в вопросе билета: это содержимое вопроса, а не иллюстрация.

## Три ловушки, которых здесь нет

1. **Коллизий имён с ядром нет** — все свои классы под `nk-`, кроме `.mono`, которого в ядре не существует. Проверяется линтером.
2. **Шорткат `background` не используется** — только `background-color`, иначе класс-носитель медиа теряет `background-image`.
3. **Шорткат `margin` не используется** — только `margin-bottom` / `margin-top`, иначе `styles.css` глушит утилиты `.mt*` из ядра, потому что подключается после `base.css`.

Отдельно: перенос строк в контентных списках включён явно (`.nk-list .grow > .t-headline`) — ядро режет такие заголовки многоточием, а здесь строка несёт не пункт настроек, а название упражнения или темы. Это нашёл `npm run audit`: 28 усечённых строк в первом проходе.
