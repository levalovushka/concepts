# Праймер — референсы

## Apple: правила, под которые концепт подстраивался

| Источник | Что взято |
|---|---|
| App Review Guidelines 2.5.4 | Фоновый режим `audio` тестируют руками. Отсюда обязательный экран Now Playing (`background`) с обложкой, названием шага и remote-командами, а не «звук в фоне» словами |
| App Review Guidelines 5.1.1 | Доступ без фичи и пустой usage-string — самый частый reject. Отсюда правило «фича, а не причина» и матрица без пустых строк |
| App Review Guidelines 2.3.1 | Скрытая функциональность. Каждая фича достижима за 2–3 тапа от корня вкладки |
| App Review Guidelines 4.2 | Minimum Functionality. Защита — узкое УТП и тест на подмену (`docs/01`) |
| HIG — Status bars, Toolbars, Tab bars, Sheets, Typography | Хром не изобретается: статус-бар, inline / large title, таб-бар 49+34, sheet с grabber 36×5 |
| HIG — Playing audio | Now Playing обязателен для фонового аудио; ±15 с — стандартный интервал для речи |
| `PHPickerViewController` | Выбор снимка без полного доступа к медиатеке. Промпт «Фото» здесь мягче, но заявлен честно: пиксели читаются, значит доступ к содержимому есть |
| `DataScannerViewController` | Чтение штрихкода на устройстве. Именно штрихкод, а не «распознавание цвета»: детерминированная операция, которую можно обещать |
| `AVAudioSession` / `MPNowPlayingInfoCenter` / `MPRemoteCommandCenter` | Минимум реализации, без которого entitlement `audio` пустой |

## Продуктовые референсы (что и почему не копируется)

| Референс | Что взято | Что сознательно не взято |
|---|---|---|
| Apple Podcasts | Длинная дорожка, «продолжить с места», Now Playing на локскрине | Лента подписок, рекомендации, соцфункции |
| Приложения-каталоги красок производителей | Идея кода и линейки как первичного ключа краски | Привязка к одному бренду: весь смысл концепта — кросс-бренд |
| Sidecar / инструменты подбора цвета | Пипетка по снимку и сопоставление с палитрой | Распознавание цвета «камерой в реальном времени»: зависит от освещения, обещать нельзя |
| Пантонные веера и системы ΔE (CIE Lab, ΔE76/2000) | ΔE как единица «насколько заметна разница»: до 2 глаз не отличает, выше 4 — другой цвет | Точные лабораторные измерения: в концепте значения — часть контент-пака, а не результат замера на устройстве |
| EAN-13 (GS1) | Настоящая структура кода в `barcode.svg`: 95 модулей, паритет по первой цифре, контрольная цифра | Реальные штрихкоды реальных производителей: код в примере вымышленный |

## Терминология домена

| Термин | Что значит |
|---|---|
| Праймер | Грунт. Первый слой, с которого начинается покраска — отсюда название |
| База / тень / эджинг | Три обязательных этапа: основной тон, затемнение углублений, высветление рёбер |
| Смывка (wash) | Жидкая тёмная краска, которая сама затекает в щели |
| NMM | Non-Metallic Metal — имитация металла обычными красками |
| Замес | Смесь двух-трёх красок в пропорции, чтобы получить оттенок, которого нет в баночке |
| Партия (lot) | Номер производственной партии: в другой партии тот же код может дать другой оттенок |
| 28 мм | Стандартный масштаб миниатюр варгейминга |

## Бренды красок в концепте

`Ferrum Colors`, `Vellum`, `Kolos`, `Prizma` — **вымышленные**. Реальные производители не упоминаются: концепт показывает механику кросс-бренд соответствия, а не заявляет права на чужие каталоги. То же с кодами (`FC-4127`) и штрихкодом.
