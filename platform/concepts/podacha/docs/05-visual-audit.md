# Визуальный аудит

Проверены все исходные и генерируемые auth-экраны: иерархия, прокрутка, нижняя навигация, длинный контент, denied-состояния и кликабельные цели. Изображения представлены только нейтральными .ph-плейсхолдерами. Основные продуктовые экраны сохраняют узнаваемую VK-плотность, а auth намеренно отличается композицией кухонной карточки.
