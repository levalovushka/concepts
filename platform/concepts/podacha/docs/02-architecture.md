# Архитектура

Основные сущности: автор, публикация, рецепт, проверка и совместная готовка. Публикация принадлежит автору и может ссылаться на рецепт; проверка принадлежит рецепту; готовка использует зафиксированную версию шагов.

Медиа хранится в управляемом Storage, данные — в Firestore с security rules, вход — через SDK провайдера и Keychain.
