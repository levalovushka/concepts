# App Store

Категории: Social Networking / Food & Drink. Возраст: 13+. Бесплатно; один контекстный промо-блок. ATT запрашивается только по явной кнопке настройки рекомендаций. Фото, камера, микрофон, контакты, место, календарь и локальная сеть имеют отдельные действия и рабочие fallback-сценарии.

Разговор кухни открывается из вкладки «Чаты» и сохраняет контекст текущего шага. Телефон в топбаре запускает настоящий групповой VoIP-вызов ведущей и участников через CallKit; без доступа вопрос можно задать текстом. Именные уведомления включаются только в Профиль → Настройки → Сообщения кухни.
