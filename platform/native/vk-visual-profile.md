# Визуальный профиль ВКонтакте

Источник правды для мимикрии. Выведен из реальных скриншотов приложения ВК
(лента, профиль, сообщество, сервисы, видео, музыка, мессенджер).

Правило: **мимикрия — почти пиксель-в-пиксель**. Фирменные цвета использовать можно.

---

## 1. Цвета

| Роль | HEX | Где |
|---|---|---|
| Акцент | `#0077FF` | активный таб, ссылки, кнопки, «Показать всё» |
| Фон экрана | `#EDEEF0` | под карточками |
| Карточка | `#FFFFFF` | все блоки контента |
| Текст основной | `#000000` | заголовки, имена, текст поста |
| Текст вторичный | `#818C99` | время, метаданные, подписи |
| Текст третичный | `#99A2AD` | плейсхолдеры полей |
| Разделитель | `#E7E8EC` | линии внутри карточек |
| Поле / капсула | `#F2F3F5` | поиск, пилюли действий, фильтры |
| Позитив | `#4BB34B` | рост курса, онлайн |
| Ошибка | `#E64646` | |

Тёмная тема — инверсия по тем же ролям, акцент сохраняется.

## 2. Геометрия

- Карточка: радиус **12**, **без тени**, край в край по горизонтали с полем **0**
  (карточка занимает всю ширину, внутренний паддинг 12–16).
- Зазор между карточками: **8**.
- Кнопка / пилюля: радиус **10**, высота **44** (крупная) и **32** (пилюля-фильтр).
- Аватар: круг **40** в ленте, **48** в списке диалогов, **круг ~96** в профиле.
- Поле поиска: капсула, высота **40**, фон `#F2F3F5`.
- Сетка фото профиля: **3 колонки**, зазор **2**.

## 3. Компоненты-сигнатуры

**Шапка экрана.** Крупный жирный заголовок слева (28–30, bold), справа в ряд иконки-действия
(плюс, поиск, колокольчик) синим `#0077FF`, размер ~24. Слева от заголовка бывает мини-аватар.

**Табы разделов.** Горизонтальный ряд под шапкой: активный — **чёрный жирный + синяя линия
снизу**, неактивные — серые `#818C99` без линии. Не сегмент-контрол.

**Пилюли-фильтры.** Горизонтальный скролл капсул: активная — светло-синий фон + синий текст,
остальные — `#F2F3F5` + чёрный текст. Часто с иконкой слева.

**Действия поста.** Ключевая деталь ВК: лайк, комментарий, репост — **каждое в отдельной серой
капсуле** (`#F2F3F5`, радиус 10, высота 32) с иконкой и числом. Просмотры — справа, без капсулы,
иконка глаза + число серым.

**Истории.** Ряд кругов сверху ленты: аватар 56–64, у непросмотренных **синяя обводка 2**,
у своей — синий кружок «+» в правом нижнем углу. Подпись под кругом 11–12, одна строка, обрезается.

**Карточка поста.** Аватар 40 → имя (жирное 15) + под ним время и источник серым 13 →
три точки справа. Текст 15/20. Медиа **край в край карточки** (без внутреннего поля).
Ниже ряд действий-капсул.

**Профиль.** Обложка на всю ширину (~200) → **круглый аватар** по центру, наложен на границу
обложки и белой карточки → имя по центру (24 bold) + синяя галочка → статус серым по центру →
строка «город · Подробнее» с иконками → **синяя кнопка на всю ширину** (радиус 10, высота 44) и
рядом две квадратные кнопки 44×44 с иконками → отдельная карточка «N подписчиков» →
пилюли-табы (Фото / Клипы / NFT) → сетка 3 колонки → «Показать всё ›» синим по центру.

**Список диалогов.** Аватар 48 → имя жирное + последнее сообщение серым (одна строка) →
справа время сверху и **синий бейдж-капсула** с числом непрочитанных снизу.

**Тред.** Входящие — белые баблы слева, исходящие — **цветные (синий/фиолетовый градиент)**
справа, радиус 16, время 11 серым. Поле ввода: «+» слева, капсула «Сообщение», эмодзи,
микрофон справа.

**Таб-бар.** 5 вкладок, иконка + подпись 10–11, активная синяя, неактивные `#818C99`.

**Сетка сервисов.** 4 колонки: цветная скруглённая плашка 56 с иконкой + подпись под ней 12.

| Заголовок секции в карточке | 20 bold |
| Имя автора | 15 semibold |
| Текст поста | 15 regular, интерлиньяж 20 |
| Метаданные | 13 regular, `#818C99` |
| Подпись под иконкой | 12 regular |
| Таб-бар | 10–11 |

## 5. Ритм экрана

Экран ВК — **лента карточек на сером фоне**, а не сплошной белый список. Каждый смысловой блок —
отдельная белая карточка. Между карточками всегда виден серый фон. Это первое, что читается как
«ВК», и это важнее любой отдельной иконки.

## 6. Ограничение проекта

Изображений нет — только SF Symbols. Значит там, где у ВК фото, у нас идёт медиа-блок той же
геометрии (край в край, та же высота, тот же радиус), заполненный системной графикой. Геометрия и
ритм сохраняются точно — меняется только содержимое кадра.
