# App Store assets

Генератор собирает готовую серию App Store-скриншотов из живого HTML-прототипа концепта. Источник интерфейса тот же, что у лаунчера: отдельные статичные макеты для стора не расходятся с продуктом.

```bash
cd platform
npm run app-store -- scene
```

Результат лежит в `concepts/<slug>/assets/app-store/`:

- полный JPEG-набор в выбранном шаблоне;
- адаптивные iPhone-наборы 6.9″, 6.5″, 6.3″ и 6.1″, а для `targetSet: vk-video` ещё iPad 13″ landscape;
- contact sheet единой визуальной системы `studio`;
- `manifest.json`, README и ZIP;
- ссылка на ZIP рядом с документами в собранном лаунчере.

В штатном цикле нового концепта отдельная команда не нужна: `npm run review -- <slug>` после review bundle запускает генератор, а финальная сборка показывает готовые кадры прямо во вкладке «Документы». Каждый кадр открывается в полном размере; ZIP остаётся рядом как действие скачивания.

## Настройка концепта

Без настроек серия выводится из `positioning.evidenceScreens` и метаданных экранов. Генератор сам определяет светлую или тёмную серию по первому продуктовому экрану и берёт интерфейсный accent token из `styles.css`, а не случайный маркетинговый цвет. Для финального copy добавьте в `appStore`:

```json
"assets": {
  "locale": "ru-RU",
  "template": "studio",
  "devices": ["iphone-6.9", "iphone-6.5", "iphone-6.3", "iphone-6.1", "ipad-13-landscape"],
  "screens": [
    {
      "screen": "home",
      "headline": "Одна сильная польза",
      "body": "Короткое доказательство, а не пересказ интерфейса"
    }
  ]
}
```

Разово выбрать экраны можно из CLI:

```bash
npm run app-store -- scene --screens home,watch,moment
```

Визуальные правила общие для всех концептов:

- один размер и положение телефона во всей серии;
- прямой крупный мокап без наклона и декоративного Dynamic Island;
- заголовок не более двух строк, без конечной пунктуации;
- неразрывные пробелы после коротких русских предлогов и союзов;
- чистый тоновый фон с лёгким interface accent glow, без размытого скриншота;
- отдельная широкая iPad-композиция: чистая редакционная типографика без подложки и крупное устройство с безопасными полями.

При необходимости тему и акцент можно явно переопределить полями `appStore.assets.tone` (`light` / `dark`) и `appStore.assets.accent` (`#RRGGBB`). Это escape hatch, а не обязательная настройка каждого концепта.

По умолчанию генератор создаёт четыре iPhone-каталога: 1320×2868 (6.9″), 1284×2778 (6.5″), 1206×2622 (6.3″) и 1170×2532 (6.1″). Каждый размер рендерится отдельной адаптивной вёрсткой, а не масштабируется из готового JPEG. Для загрузки в App Store Connect достаточно мастер-набора 6.9″, но остальные экспорты удобны для проверки композиций и совместимых витрин. iPad-экспорт автоматически включён только для VK Video; для другого набора его нужно явно добавить и подтвердить `appStore.assets.ipad: true`.

Рамка устройства в шаблонах нейтральная, программная и не выдаётся за официальный Apple Product Bezel. Если нужен узнаваемый официальный мокап iPhone/iPad, его следует подключать отдельным лицензированным ресурсом Apple и использовать без модификаций.
